## 结论

1. v2 在这两批上的区分度**全部来自 1.1（研发能力）**：4 家申请人授权发明均为 0 → 25/25 全非正常。
2. 剔重名确实生效：陈海佳 6 条、林美华 7 条、谢章龙 3 条全部按"领域不同"剔除，有效件数归零（否则这三人会被 ≥5 直接判死，且理由是错的）。
3. 跨机构维在这两批上从未触发——因为剔重名后只剩本案一家。**这维要在"真一人挂多家"的样本上才能验证**，现有样本不足。
4. ⑤b 仍命中 23 件（它看全部年限，不含剔重名），是 v2 结论的主要"冗余命中项"，报告里要避免重复计数。
