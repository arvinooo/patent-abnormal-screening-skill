## 结论

1. v2 在这两批上的区分度**全部来自 1.1（研发能力）**：4 家申请人授权发明均为 0 → 25/25 全非正常。
2. 剔重名确实生效：陈海佳 6 条、林美华 7 条、谢章龙 3 条全部按"领域不同"剔除，有效件数归零（否则这三人会被 ≥5 直接判死，且理由是错的）。
3. **跨机构维在这两批上 0 命中**：剔重名后每人只剩本案一家（谢建政 2 家也在允许范围内）。这维要在"真一人挂三家无关联公司"的样本上才能验证，现有样本不足。
4. **原 ⑤b 已并入跨机构**：v1 里 23 件挂 ⑤b，v2 改"先剔重名 + 允许 2 家 + 按关联聚组"后 0 件命中。报告不再出现"⑤b"字样。
5. 常见名（王猛）处理：件数不可采信 → `pending`，但研发能力照判；因为"无论件数多少，申请人没授权发明就不过"，所以结论仍是非正常。
