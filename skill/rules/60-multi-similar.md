# 60 多件相似申请（⑥）

> 跨案维度：先把同批案子"成组"，再看这组是不是拆分型/复制型。不成组就不判。

## 1 成组（不成立就不判）

- 同一申请人或关联主体 **≥2 件** + **12 个月内**（T06）
- 关联主体并组：须其自身 ≥2 件，或有股权/实控人证据
- 组内每件都要有文本（缺文本的成员不并入，报告注明）
- **只有 1 件的主体不构成组** → 该维 `na`；不得为凑组并入邻组

## 2 型A 复制型（T07）

正文 20 字 shingle 重合率 **≥50%**，且技术问题/原理一致、差异仅参数 → 「内容明显相同」。

```python
def shingles(text, k=20):
    t = "".join(text.split())
    return {t[i:i+k] for i in range(len(t) - k + 1)}

def overlap(a, b, k=20):
    A, B = shingles(a, k), shingles(b, k)
    return len(A & B) / max(1, len(A))      # 重合率 = 交集 / 先申请的那份
```

> 实测提醒：拆分型案件的文本重合率**可以极低**（芯烨 5 件仅 5.6%–7.3%）。低重合率不等于不成组——型B 靠标题/主题判，不靠文本相似。

## 3 型B 拆分型

判据只一条：组内各件发明名称**全部围绕同一产品/设备**（产品级尺度）。

- 同一产品的结构件、控制方法、装配工艺、配套方法 → 都算同主题
- 组内跨多类设备（硫化机 + 输送线 + 模具）→ **整组不构成**，不做子组拆分
- 产品级 vs 行业级：`打印机` 是产品级；`橡胶机械` 是行业级
