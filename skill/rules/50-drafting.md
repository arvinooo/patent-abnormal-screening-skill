# 50 技术领域（③）与撰写（④）

> 只判文本，不取外部数据。判据沿用 v1，没有改口径。

## ③ 技术领域

### 高风险四类（清单）

| 类别 | 定义 |
|---|---|
| 机械装置 | 纯机械结构/装置，无电气、控制或材料创新 |
| 生活类发明创造 | 日用品、生活小工具、家居小改 |
| 计算机算法 | 纯计算方法/数学模型，无具体应用系统与工程手段 |
| 方法步骤图的系统 | 纯流程/步骤图，无装置或技术手段支撑 |

### 判定：三个问题，全"否"才判过

1. 权1 里有没有承载技术效果的**物理结构或工程手段**？（还是只有计算步骤、流程、模块名）
2. 把计算/步骤去掉，方案还剩什么实质内容？（什么都不剩 → 疑）
3. 技术效果是不是各特征效果的**简单相加**、没有协同（1+1>2）？（是 → 疑）

**命中清单 且 方案无「技术问题—技术手段—技术效果」实质链** → 不过。

### 边界判例（沿用 v1）

| 案 | 特征 | 判定 |
|---|---|---|
| 冰箱风道组件 | 明确解决冷气分布不均/凝露，有结构-效果链 | 过（不因"机械"判不过） |
| 磨煤机出力计算 | 纯计算方法，无应用系统与工程手段 | 不过 |
| 相对指针输入校验系统 | 纯软件模块组合，模块各自独立发挥作用 | 不过 |
| 成本数据降维存储 | 纯算法 + 存储步骤，无工程手段 | 不过 |
| 节能型道路监控装置 | 机械装置，无超出常理的改进链 | 不过 |

判定看**技术领域原文 + 权1**，不是 IPC 号机械套用。

## ④ 撰写

只两条，命中任一 → 不过：

### 1 缺多级布局

独权即最窄——整机部件、整条工艺、全部优选参数写进独权，从权只能补无关细节或换个说法，没有退路。

健康形态：独权上位概括，从权逐层收窄（先加功能 → 再加结构 → 落参数/材料），任一层无效下一层兜得住。

### 2 步骤顺序或参数范围写死

- 方法类：把步骤全序（S1→S2→S3…）连同工艺参数（温度/时间/浓度/转速）写进独权
- 产品类：写死只对应某台样机的定量限定（"行程 20mm""八个阀门"），且该数值并非解决技术问题所必需

**不算写死**：组合物/材料类的配比区间（重量份）是该领域常规写法；数值放从权、独权只写"预设值/阈值"等变量表述。

「修改后仅改附图/调整措辞、无实质改进」不在判据内，不作为④依据。

## 实务提示

- 实用新型普遍是"独权写整机 + 从权补细节"，这是行业常规，别见到整机独权就判不过；要看**从权有没有对发明点的上位退路**。
- 判不过时证据写清：权项号 + 哪几个部件/参数被写死在独权里。
- 判过也要在报告里写一句"独权-从权布局健康/临界"，方便复核。
