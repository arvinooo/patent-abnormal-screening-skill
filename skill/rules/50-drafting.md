# 50 技术领域（③）与撰写（④）

> ③ 按**先归四类，再分流**判：
>
> - **不属于四类** → ③ 直接过，**不看创新度**（不花检索额度）
> - **生活类** → 不过；**计算机算法 / 方法步骤图** → 仅「跨域算法」（主体无科技属性且非院校院所）不过
> - **机械装置 / 方法步骤图的系统** → 才走创新度判定（专利库检索对比文件，阈值 `00-thresholds.md` T10–T12）
>
> ④ 撰写判三件事：独权-从权布局、整机零件清单化、T13 撰写厚度。

## ③ 技术领域与创新度

### 3a 第一步：归四类（只看权1 + 说明书技术领域段，不按 IPC 号机械套用）

| 类别 | 归类判据（需同时成立） | 不算本类 |
|---|---|---|
| **机械装置** | ①方案主体是机械结构/装置，创新点落在部件、结构、连接关系上；②带常规电机、气缸、泵、阀等执行件仍算本类；③无材料配方创新、无控制算法创新，方案主体不是工艺或系统。 | 有电气控制算法/材料创新的（→ 非四类）；主方案是化工/冶金/生物工艺的（→ 非四类）；纯软件/算法（→ 计算机算法） |
| **生活类发明创造** | ①技术对象是个人/家庭消费品：家居、厨房、清洁、个人护理、穿戴、文具、玩具、母婴、宠物；②应用场景不含生产/工业/医疗/农业作业环节；③创新点只落在形态、收纳、便携、外观、使用便利性，**没有**性能/安全/工艺/效率的量化指标；④IPC 落在消费类小类（A47 家具家居、A45 手持/旅行用品、A46 刷类、A41–A43 服装鞋帽、A63 游戏玩具等）。 | 工业设备（结构再简单也不算）、医疗器械、农业机具、消防安防器材、商用清洁设备 |
| **计算机算法** | ①权1 主题是方法/系统/模型，不含装置或设备的执行体；②拆解后 **≥80%** 特征为计算类动作（计算/数据处理/判定/匹配/训练/优化/存储/编码）；③无传感器、执行器、工艺参数等工程约束；④技术效果只落在准确率/效率/速度/存储量等纯计算指标。 | 算法 + 具体工程系统（"××设备的控制方法"含设备结构）；图像/信号处理落到具体检测装置 |
| **方法步骤图的系统** | ①权1 是流程/步骤序列（S1→S2→S3…）；②各步只有"模块处理/数据流转/判定"这类描述，**没有装置、设备或工艺参数**支撑；③换个领域也能原样套用。 | 有具体设备/塔器/工艺参数的方法（→ 非四类）；步骤里含结构改进的（→ 机械装置） |

**归类要落到一类，写清"归到哪类 + 依据权项号"**；四类都不命中 → 记 `非四类`。

### 3b 第二步：按归类分流

| 归类结果 | ③ 判定 | 是否检索 |
|---|---|---|
| **非四类** | `pass`（报告写一句"不属四类清单，按规则不看创新度"） | **不检索** |
| **生活类发明创造** | `fail`（T08） | 不检索 |
| **计算机算法 / 方法步骤图的系统** | 看**主体是否匹配**：申请人名称与经营范围均无科技属性、且非院校院所 → `fail`（跨域算法，T08）；否则 `pass` | 不检索 |
| **机械装置** | 走 3c 创新度 | 检索 |

**为什么算法类要按主体分层**：算法方案本身在院校、科研院所、软件企业是常态。已判定正常的 33 件中 8 件属 G06/H04 信息类，按"算法一票不过"误伤 24%；已判定非正常的 134 件中该类占 29%。按"主体无科技属性"过滤后，异常集命中 11%、正常集命中 0%。

**跨域算法的判据**：申请人名称、经营范围均不含 科技/技术/信息/智能/软件/网络/数据/电子/通信/自动化/计算机/数字/物联/检测/技术服务/技术推广；且主体不是院校、院所、医院、政府机构。一个做金属容器的厂报"基于 AI 的输送皮带撕裂检测"，才属于此类。

### 3c 创新度判定（只有机械装置、方法步骤图的系统才跑）

> 对应 77 号令第三条**第（二）项**"抄袭、简单替换、拼凑现有技术"与**第（一）项**后半"要素简单组合"。
> 判的是：**这篇是不是炒冷饭**，不是"有没有结构"。

**第 1 步 拆创新点**

从独权拆 5–10 个技术特征，编号 `F1…Fn`，每个挂权项号；再从从权/说明书里补 1–3 个声称的区别点，标「（声称）」。特征要拆到「部件/步骤 + 连接关系/参数」这一粒度，别写成"一个装置"这种整段。

**第 2 步 两路检索（必须两路，单路会漏）**

- **布尔**：`AB=(领域词) AND AB=(功能词)` / `TI=(…)`，至少两组——一组精确（领域专有词，如「珠光砂」「扒砂」），一组上位（功能词，如「粉料密闭输送」「负压除尘」）。关键词带同义词与上下位词；时间窗 `AND AD=[19850101 TO 本案申请日]`。
- **语义**：incoPat 语义检索页输入「独权原文 + 创新点清单」，结果带相关度百分比。
- 合并去重，只留**申请日或公开日早于本案**（本案无申请日则早于查询日）的同领域文件；按相关度取前 8，对最接近的 3 篇取权利要求（结果页「显示字段」勾选「首项权利要求(中文)」）。
- 布尔与语义的写法、字段码见 `data-sources.md` §8、§13。

> 实测：语义检索会漏掉冷门领域的精确文件（空分冷箱扒砂，高相关度前列仍是气流粉碎/筒仓惰化一类），而布尔 `AB=(珠光砂) AND AB=(空分)` 能捞到 61 篇、`TI=(扒砂装置)` 8 篇精确命中。**所以两路都要跑，缺一路判 pending。**

**第 3 步 逐特征对照**

算两个数：

```text
单篇覆盖度 k/N   = 该篇公开的特征数 / 本案特征总数（公知常识、常规选择不算"公开"）
合并覆盖度       = 最接近的 1–2 篇合并后公开的特征数 / N
```

同时给差异定性，四选一：

| 定性 | 含义 | 例 |
|---|---|---|
| `常见替换` | 等价手段替换（螺栓换卡扣、电机换气缸） | 绞龙换成螺旋输送带 |
| `公知常识` | 本领域默认做法（加过滤器、加保温层） | 加一层滤网 |
| `实质改进` | 解决新问题、有量化效果或结构协同 | 双道密封隔离腔 + 氮气吹扫隔开粉尘与电机腔 |
| `协同` | 特征间互为条件，1+1>2 | 多点分层卸料必须配锁气阀才能维持负压 |

**第 4 步 判（T10–T12）**

| 情形 | 判定 |
|---|---|
| 单篇覆盖度 **≥80%** 且剩余差异属「常见替换/公知常识」 | **不过**（炒冷饭） |
| 单篇覆盖度 = 100% | **不过**（X 类全文命中） |
| ≤2 篇合并覆盖 100%，且差异无「协同」 | **不过**（拼凑，对应第（一）项后半） |
| 其余（覆盖度 <80%，或差异为实质改进/协同） | 过 |
| 最接近文件是**本案申请人的在先申请**，且覆盖度 ≥80% | **不过**（自我重复申请，更硬的一条） |
| 检索没捞到同领域文件 / 权项取不到 | `pending`（不默认放过，也不凭空判不过） |

**报告必须给**：最接近文件号 + 公开日 + 单篇覆盖度 k/N + 合并覆盖度 + 逐特征对照表 + 差异定性理由。没有这张表，结论不可复核。

## ④ 撰写

三条，命中任一 → 不过：

### 1 缺多级布局

独权即最窄——整机部件、整条工艺、全部优选参数写进独权，从权只能补无关细节或换个说法，没有退路。

健康形态：独权上位概括，从权逐层收窄（先加功能 → 再加结构 → 落参数/材料），任一层无效下一层兜得住。

### 2 整机零件清单化

排在最先的那条权利要求，从最外层壳体一路列到内部每一个零件，每个零件都带附图标记，只写"设有／连接／固定"，不写该零件解决什么技术问题。

判据（量化见 00-thresholds.md 的 T13 第一项）：

- 权1 中附图标记（数字）≥8 个 → 计 1 分，进入 T13 计分
- 附带条件：功能限定（"用于…的"）占比低，多为部件名称罗列

**不算清单化**：

- 方法类权利要求按 S1→S2→S3 写全步骤 —— 这是方法权项的必要写法，不作为撰写缺陷
- 组合物／材料类的配比区间（重量份）是该领域常规写法
- 数值放从权、独权只写"预设值／阈值"等变量表述

标定来源：已判定非正常的 134 件中 69 件（51.5%）权1 附图标记 ≥8；已判定正常的 33 件中 4 件（12.1%）。

### 3 撰写厚度不足（T13）

按 00-thresholds.md 的 T13 计分：无验证数据、说明书段落 <40、"第一／第二"占位 ≥10、具体参数 <2 处。≥4 分判不过；3 分与主体证据联判。

标定来源：已判定非正常的 134 件平均 3.31 分（≥4 分占 46%）；已判定正常的 33 件平均 0.94 分（≥4 分占 0%）。

「修改后仅改附图/调整措辞、无实质改进」不在判据内，不作为④依据。

## 实务提示

- 实用新型普遍是"独权写整机 + 从权补细节"，这是行业常规，别见到整机独权就判不过；要看**从权有没有对发明点的上位退路**。
- 判不过时证据写清：哪几个部件/参数被写死在排在最前面的那条权利要求里；报告不出现「权1 / 独权 / 从权」等术语，写「排在最前面的那条权利要求」「后面几条权利要求」。
- 报告写法示例（律师可读）：`排在最前面的那条权利要求把校准的六个步骤全部写完，包括核心的「以校验负载的特征阻抗值为索引，建立补偿映射关系」；后面 9 条只是采样、滤波、归一化等实现细节。删掉任一步流程不成立，没有更宽的方案可以退。`
- 判过也要在报告里写一句"独权-从权布局健康/临界"，方便复核。
- ③ 的「创新度」只判**技术方案是否炒冷饭**，不等同于审查阶段的新颖性/创造性结论；报告措辞统一写"对比后创新度不足/足够"，不写"无新颖性"。
