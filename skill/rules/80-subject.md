# 80 第二层：主体面板

> 只对**存疑**案跑。文本层已看过文件，本面板看的是"这个主体像不像真在研发"。
> 九项全部参与判定：任一项成立即认定非正常。每项都写明成立条件——主体身份本身不作为理由，必须叠加事实。

## 判定规则

```text
九项任一项成立 → 非正常
九项全部不成立 → 可提交
任一项数据缺失 → 存疑（写明缺哪项）
```

为什么每项都要条件：主体身份（院校、自然人、社保人数）在正常案件里同样常见，单凭身份定案会大面积误判。下面每项都写成"身份 + 事实"的组合。

## 一、发明人件数（T20）

```text
第一发明人，本案申请日往前 12 个月，剔重名后有效件数 ≥5 → 成立
```

剔重名口径见 `60-inventor.md`。实测：非正常样本 42/69（61%），正常样本未测。

## 二、跨机构（T21）

```text
剔重名后的记录涉及的申请人，按关联关系聚组后 ≥3 组 → 成立
```

聚组口径见 `70-cross-org.md`。允许 2 家（本案 + 1 家）。

## 三、授权发明专利（T23）

```text
申请人到本案申请日，授权发明专利 = 0，且申请人为企业 → 成立
```

| 情形 | 处理 |
|---|---|
| 0 件且为企业 | 成立 |
| ≥1 件 | 不成立 |
| 院校、院所、医院、自然人 | 不适用 |

口径：只认申请人本体，不含母子公司与曾用名；按结果页「发明授权」类型统计 ≥1 即算，不问是否终止或受让取得；基准日为本案申请日。检索式 `AP=(申请人) AND AD=[19850101 TO 基准日]`。

**副作用必须写进报告**：纯实用新型客户天然 0 件，会整批成立。批次开始前须与用户确认这类客户是否豁免。

实测：非正常样本 16 家中 5 家为 0（31%），正常样本 6 家中 1 家为 0（17%）。

## 四、代理师代理量（T22）

```text
代理师近 12 个月在本所提交的申请总量 ≥300 → 成立
```

取数 `xys_agent.py <姓名> --anchor <本案申请日>`，本所口径、取总量（含公海）。

| 情形 | 处理 |
|---|---|
| ≥300 件 | 成立 |
| <300 件 | 不成立 |
| 页面有该行、数值为 0 | 不成立 |
| 该所名录查无此人（外部代理所署名） | 不可评估，不参与 |

外部代理所的案件本项记不可评估，不得据此把整案降档。

## 五、分类号集中（T24）

```text
主分类为 G06 或 H04，且申请人名称与经营范围均无科技属性、也非院校院所 → 成立
```

单独看分类号没有区分度：G06 在非正常样本占 29%、正常样本占 24%。只有叠加"主体无科技属性"才成立。

## 六、①类型（T25）

```text
申请人为自然人（含个体户、家庭式组合）
或 申请人为文化、传媒、茶业、贸易类公司且主营与技术对象无交集
→ 成立
```

| 主体性质 | 处理 |
|---|---|
| 自然人、个体户 | 成立 |
| 文化／传媒／茶业／贸易类公司，主营无交集 | 成立 |
| 院校、医院、研究所 | **不成立**，只记背景 |
| 一般企业 | 不成立，只记背景 |

院校、医院不因身份命中：已确认正常样本中院校/院所占 76%，非正常样本中仅占 2%，按身份判会误杀四分之三的正常案。

边界：「××职业培训学校有限公司」是企业；「××电力设计院有限公司」是企业。

## 七、①科技属性（T26）

```text
申请人名称与经营范围均无研发类业务，且技术对象属信息、算法、数据类 → 成立
```

研发类业务的判定：名称或经营范围含 科技/技术/智能/电子/软件/网络/数据/生物/医药/新材料/新能源/半导体/自动化/通信/检测/机器人/光电，或含 技术开发/技术咨询/研发/软件开发/系统集成/集成电路设计/检验检测。

| 结论 | 处理 |
|---|---|
| 有以上任一项 | 不成立 |
| 名称带"科技"但经营范围纯贸易、咨询 | 记"弱"，需与第五项合并判断 |
| 均无，且技术对象属信息类 | 成立 |

与第五项的关系：第五项看分类号、本项看经营范围，两者同时满足时按一项证据计，不重复加成。

## 八、①社保人数（T27）

```text
参保人数 <3，且授权发明专利 = 0，且经营范围无研发类业务 → 成立
```

| 参保人数 | 处理 |
|---|---|
| <3 | 记"弱"；须与 0 授权发明、无研发范围同时成立才命中 |
| 3–10 | 灰区，只记背景 |
| ≥10 | 不成立 |

不单看社保：非正常样本中参保 <3 占 25%，正常样本中占 33%——正常案里更常见。社保是年报公示口径，可能滞后；新设未申报会显示 0 或空，要区分"0 人"与"不在库"。

## 九、①主营匹配（T28）

```text
技术对象与申请人经营范围、国标行业无交集，且申请人非院校、非医院 → 成立
```

| 结论 | 处理 |
|---|---|
| 一致 | 不成立（就是主营产品线） |
| 相邻 | 不成立（同产业链上下游，或范围里有对应技术服务） |
| 无关，且非院校医院 | 成立 |

院校、医院的技术方向常超出经营范围，本项对其不适用。

## 豁免（专精特新）

范围：专精特新"小巨人"（国家级）+ 专精特新中小企业（省级）。
不含：创新型中小企业、科技型中小企业、高新技术企业。

生效：本节第三项（授权发明专利）与第六至九项（类型、科技属性、社保、主营）。
不生效：第一项、第二项、第四项、第五项。

命中后标"豁免"，照常记录数值，报告中不写为否决理由。

## 报告写法

成立项写事实，其余写背景段：

```text
- 原因：申请人到本案申请日没有授权发明专利（0 件）；参保 2 人，经营范围为金属容器制造。

（背景：申请人为一般制造企业，主营与技术对象相邻；代理师近 12 个月 22 件。）
```
