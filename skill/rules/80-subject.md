# 80 第二层：主体面板

> 只对**存疑**案跑。文本层已经看过文件，本面板看的是"这个主体像不像真在研发"。
> 七项全部跑、全部记录结论；但只有三项参与判定，四项只作画像。原因见每项的实测数据。

## 判定规则

```text
判定级（三项，任一命中即非正常）：
  1.1 授权发明专利 = 0 且申请人为企业
  ② 代理师代理量 ≥300
  1.6 分类号集中于信息类（G06/H04）且申请人无科技属性

画像级（四项，只记录，不参与判定）：
  ①类型、①科技属性、①社保、①主营匹配

结论：
  判定级命中 ≥1 → 非正常
  判定级全过 → 可提交（画像级结论写进复核段）
```

为什么这么分：画像级四项在已确认样本上的误判率都高于或接近命中率（见下表），单独使用等于按身份定罪。它们全部跑、全部写进报告，但不得作为否决理由。

## 判定级三项

### 1.1 授权发明专利（T23）

查本案申请人到本案申请日为止有没有授权发明专利 ≥1 件。

| 情形 | 处理 |
|---|---|
| 0 件且申请人为企业 | **命中** |
| ≥1 件 | 不命中 |
| 申请人是院校、院所、医院、自然人 | 不适用（记 na） |

口径：只认申请人本体，不含母子公司与曾用名；"有授权"按结果页「发明授权」类型统计 ≥1 即算，不问是否终止、是否受让取得；基准日为本案申请日。

检索式：`AP=(申请人) AND AD=[19850101 TO 基准日]`。

**副作用必须写进报告**：纯实用新型客户天然为 0 件，会整批命中。这一条是业务决策，若客户群以实用新型为主，须在批次开始前说明豁免。

实测：已确认非正常样本 16 家中 5 家为 0（31%），已确认正常样本 6 家中 1 家为 0（17%）。

### ② 代理师代理量（T22）

代理师近 12 个月在本所提交的申请总量 ≥300 件。

取数：`xys_agent.py <姓名> --anchor <本案申请日>`，本所口径、取总量（含公海）。

| 情形 | 处理 |
|---|---|
| ≥300 件 | **命中** |
| <300 件 | 不命中 |
| 页面有该行、数值为 0 | 不命中 |
| 该所名录查无此人（外部代理所署名） | 记 na，不参与判定 |

**不可评估要说清**：本所统计页只覆盖本所名录，外部代理所的案件一律查无此人。这类案件本项记 na，不得据此把整案降为不过。

### 1.6 分类号集中（T24）

本案主分类落在信息类（G06 / H04），且申请人名称与经营范围均无科技属性、也非院校院所 → **命中**。

取数：主分类号从首页 `(51)Int.Cl.` 第一位读；主体属性从企查查经营范围读。

实测：G06 信息类在非正常样本占 29%、正常样本占 24%，无区分度；只有叠加"主体无科技属性"之后才有意义。因此本项不得单看分类号。

## 画像级四项（只记录）

### ①类型（主体性质）

按设立性质判：企业、院校（大学/学院/学校/研究所/研究院，含军队院校）、医院、自然人（含个体户）。

| 主体性质 | 记录 |
|---|---|
| 院校 / 医院 / 研究所 | 记"院校类"，报告背景段写一句 |
| 自然人 | 记"自然人"，写明姓名 |
| 企业 | 记企业，若名称含"职业培训学校""设计院有限公司"按企业记 |

**不参与判定**：已确认正常样本中院校/院所占 76%，非正常样本中仅占 2%。按身份否决会误杀四分之三的正常案。

### ①科技属性

看名称与经营范围有没有研发类业务（科技/技术/智能/电子/软件/网络/数据/生物/医药/新材料/新能源/半导体/自动化/通信/检测/机器人/光电，或技术开发/研发/软件开发/系统集成/检验检测）。

| 结论 | 记录 |
|---|---|
| 强 | 有以上任一项 |
| 弱 | 名称带"科技"但经营范围纯贸易、咨询 |
| 无 | 主业文化/传媒/贸易/餐饮/咨询/投资/房地产/物流，且无研发类范围 |

只用于 1.6 的组合判断，本身不定案。

### ①社保人数（T01）

参保人数：<3 记"弱"，3–10 记"灰区"，≥10 记"正常"。

**不参与判定**：已确认非正常样本中参保 <3 占 25%，已确认正常样本中占 33%——正常案里更常见。社保是年报口径可能滞后，新设未申报显示 0 或空，要区分"0 人"和"不在库"。

### ①主营匹配

用本案技术对象/应用场景对比申请人经营范围与国标行业。

| 结论 | 记录 |
|---|---|
| 一致 | 就是主营产品线（环保设备公司报污泥脱水装置） |
| 相邻 | 同产业链上下游，或范围里有对应技术服务 |
| 无关 | 无交集（文化传播公司报阀门结构） |

**不参与判定**：判断主观，且没有正常/异常对照数据；经营范围普遍写得宽，"无关"很难成立。

## 豁免（专精特新）

范围：专精特新"小巨人"（国家级）+ 专精特新中小企业（省级）。
不含：创新型中小企业、科技型中小企业、高新技术企业。

生效：本节四项画像级 + 1.1 授权发明专利。
不生效：第二层的发明人件数、跨机构；第一层全部判据。

判定：企查查 `qop operation get_honor_info`（只返回当前有效荣誉），名称含"专精特新"。命中后标"豁免"，照常记录数值，报告中不写为否决理由。

## 报告写法

判定级命中写原因，画像级只写背景段一句：

```text
- 原因：申请人到本案申请日没有授权发明专利（0 件）。

（背景：申请人参保 2 人；主营为金属容器制造，与技术对象相邻。）
```
