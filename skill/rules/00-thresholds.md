## 第二层：主体面板（只对存疑案）

只判**文件之外的主体事实**。PDF 主体由第一层的三项判据判，本层不重复。

八项全跑，任一成立即非正常。主体身份本身不作理由，每项都要"身份 + 事实"。

| 编号 | 项 | 成立条件 | 窗口 | 数据源 |
|---|---|---|---|---|
| T20 | 发明人有效件数 | 剔重名后 ≥5 件 | 本案申请日往前 12 个月 | incoPat |
| T21 | 跨机构组数 | 聚组后 ≥3 组 | 同上 | incoPat + 企查查 |
| T22 | 代理师代理量 | ≥300 件；查无此人记 na，不参与否决 | 同 T20 | 香橼树（本所口径） |
| T23 | 授权发明专利 | 0 件且申请人为企业；院校/院所/医院/自然人不适用 | 到本案申请日 | incoPat |
| T24 | ①类型 | 自然人/个体户；或文化/传媒/茶业类且主营无交集 | — | 申请人栏 |
| T25 | ①科技属性 | 主业文化/传媒/茶业/贸易/餐饮/咨询/投资/房地产/物流，且无研发类经营范围 | — | 企查查 |
| T26 | ①社保人数 | 参保 <3 → 成立 | 取数日 | 企查查 |
| T27 | ①主营匹配 | 与技术对象无关，且非院校非医院 | — | 企查查 |

结论：任一项成立 → 非正常；八项全不成立 → 可提交；任一项数据缺失 → 存疑。

院校、医院不因身份命中：已确认正常样本中占 76%、非正常样本中占 2%。

## 边界值速查

| 情形 | 判定 |
|---|---|
| 三项判据命中两项 | 非正常 |
| 三项命中一项 | 存疑，进第二层 |
| 三项命中零项 | 可提交 |
| 发明人有效件数 = 5 | 命中（≥5 挂） |
| 发明人有效件数 = 4 | 不命中 |
| 跨机构组数 = 2 | 不命中 |
| 跨机构组数 = 3 | 查关联，无关联则命中 |
| 结构案触发第十条 | 出结论但附「核对附图」提示，不得直接判非正常 |
| 实用新型 | 不适用第十四条；仅按手段与批次判 |
| 机械类已记载工程参数 ≥3 处 | 不因缺实验数据认定 |
| 数据拿不到 | 保持存疑，不默认通过 |

## 窗口锚点

所有"12 个月"都锚**本案申请日**，往前推 365 天。

取得申请日的顺序：

1. 文本著录项 (22)；
2. 明细表给了申请号时，用 incoPat 按申请人取该批案件的结果行（结果行自带申请号与申请日），按申请号对上本案；
3. 以上都没有（撰写稿未提交、未公开）→ 锚点退化为查询日，报告必须标注。

申请号是当年顺序号，可用于判断月份量级：同一年内序号越大申请日越晚。序号与已知申请日的对照能估出月份，仅作辅助，不作定案依据。
