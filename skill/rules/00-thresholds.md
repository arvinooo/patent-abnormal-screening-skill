## 边界值速查（容易搞错的等号）

| 情形 | 判定 |
|---|---|
| 发明人有效件数 = 5 | **不过**（≥5 挂） |
| 发明人有效件数 = 4 | 走 1.1（查授权发明专利） |
| 跨机构组数 = 2 | 正常 |
| 跨机构组数 = 3 | 查关联，无关联则不过 |
| 代理师代理量 = 300 | **不过**（≥300 挂） |
| 代理师代理量 = 299 | 通过 |
| 授权发明专利 = 1 件 | 有研发能力（通过 1.1） |

## 豁免（专精特新）

- 认定范围：**专精特新"小巨人"企业（国家级）** + **专精特新中小企业（省级）**
- **不含**：创新型中小企业（省级）、科技型中小企业、高新技术企业
- 生效维度：T01、T02 以及 `rules/10` 的①类型/①科技属性/①主营匹配
- 不生效：T03、T04、T05、T06、T07、文本维、违法公德
- 判定：查 `qcc operation get_honor_info`（只返回当前有效荣誉），名称含"专精特新"
