# 80 企业资质豁免（专精特新）

> 用途：一家公司**有研发实力**（专精特新），就不能**仅因为它"规模小/主营偏/没发明授权"**被判非正常。
> 注意：豁免 ≠ 通过。豁免的维度照常算出结论，只是**不参与否决**，报告必须保留原判定。

## 1 前置判定（放在流程第 1 步）

```text
查申请人荣誉（qcc operation get_honor_info）
├ 命中"专精特新\"小巨人\"企业"（国家级）→ 豁免生效，记 waiver = {level: 国家级小巨人, year: 认证年份}
├ 命中"专精特新中小企业"（省级）        → 豁免生效，记 waiver = {level: 省级专精特新, year: 认证年份}
└ 其余（含"创新型中小企业"）            → 不豁免
```

**只认这两档**。「创新型中小企业」是梯度培育的最低档，门槛低（实测：很多普通公司都有），**不算**。
「科技型中小企业」「高新技术企业」也不算——它们是科技属性证据，不是资质豁免依据。

## 2 生效范围

| 维度 | 是否豁免 |
|---|---|
| ①类型（院校/医院/自然人/文化传媒） | ✅ |
| ①科技属性 | ✅ |
| ①社保（T01） | ✅ |
| ①主营匹配 | ✅ |
| 1.1 授权发明专利（T02） | ✅ |
| 1.2 发明人件数（T03） | ❌ |
| 2.1 跨机构（T04） | ❌ |
| ②代理师代理量（T05） | ❌ |
| ③技术领域 / ④撰写 | ❌ |
| ⑥多件相似（T06/T07） | ❌ |
| 违法公德 | ❌ |

**理由**：专精特新证明的是"这家公司有研发实力"，证明不了"这篇写得没问题""这不是抄的""代理人没爆量"。而 77 号令第 2 条讲的是诚实信用，**不看资质**。

## 3 现实提醒（写进报告，别让客户误解）

- 院校、医院、自然人**不可能**是专精特新（认定对象必须是中小企业）→ ①类型 那一行的"✅"实际上用不到。
- 真正会被救回来的只有：**是企业、但社保 <3 / 主营不匹配 / 没有授权发明专利**。

## 4 报告写法

报告只写两段（总览 + 逐件），豁免与否都在「不过原因」里说清楚：

```text
### 5. 一种阀门 · 某某阀门有限公司 · 不过

- 不过原因：本批 13 件全围绕「阀门」同一产品线，是同一产品的不同结构件分别申请

（内部记录：①社保 参保 2 人 <3、①主营匹配 无关，均因省级专精特新中小企业（2025 年认定）豁免，不参与否决；⑥ 多件相似不可豁免，据此判不过。）
```

若豁免项之外没有不可豁免的不过项 → 该件判「过」，标题行写 `· 过`，不写原因。

## 5 数据与缓存

| 项 | 说明 |
|---|---|
| 接口 | `qcc operation get_honor_info "<申请人>"` |
| 返回 | 名称 / 荣誉类型 / 级别 / 认证年份 / 发布日期 / 发布单位 |
| 有效期 | 接口**只返回当前仍有效的荣誉**，不用自己算"认定 3 年"；查过期用 `get_historical_honor` |
| 缓存 | 命名空间 `company_honor`，90 天 |
| 成本 | 1 次调用/主体（同一主体多案只查一次） |
| 失败处理 | 查无记录或接口异常 → 这一维标 `pending`（不默认放过），报告注明"资质未取到" |

## 6 判定顺序上的意义

豁免是**前置**的：先查资质，再跑企业类维度。但**结论仍要在跑完后统一汇总**（不能查到资质就直接出"正常"）——因为 ③④⑥/违法/2.1/② 这些不豁免的维度还没跑。
