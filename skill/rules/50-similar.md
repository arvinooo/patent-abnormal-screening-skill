# 50 多件相似（拆分型 / 复制型）

> 跨案维度：先把同批案子"成组"，再看这组是不是把一件产品拆成多件申请、或者多件内容雷同。
> 只有一份文本时不判。

## 1 成组

```text
同一申请人或关联主体 ≥2 件
且 申请日在 12 个月内
且 组内每件都有文本
```

关联主体并组须其自身 ≥2 件，或有股权、实控人证据。只有 1 件的主体不构成组，不得为凑组并入邻组。

## 2 拆分型

判据只有一条：**组内各件发明名称全部围绕同一产品/设备**（产品级尺度）。

- 同一产品的结构件、控制方法、装配工艺、配套方法 → 都算同主题
- 跨多类设备（硫化机、输送线、模具、管道检测）→ 不构成
- 同一产线上的两台不同设备 → 边界情形，默认不构成

判例：

| 组 | 标题概况 | 判定 |
|---|---|---|
| 某打印机企业 9 件（69 天） | 结构、控制方法、切刀、散热、装配工艺、蓝牙打印、图片裁剪 | 拆分型 |
| 某轮胎企业 9 件（12 个月） | 硫化机、输送线、组合模具、管道检测 | 不构成 |
| 某微流控企业 4 件（6 个月） | 清洗、喷墨补偿、打印数据生成、移液控制 | 拆分型 |

## 3 复制型

正文 20 字片段重合率 ≥50%，且技术问题、原理一致，差异仅参数 → 内容明显相同。

```python
def shingles(text, k=20):
    t = "".join(text.split())
    return {t[i:i+k] for i in range(len(t) - k + 1)}

def overlap(a, b, k=20):
    A, B = shingles(a, k), shingles(b, k)
    return len(A & B) / max(1, len(A))
```

实测提醒：真实非正常案不靠文本雷同——同一批 103 对同主体配对中，重合率 ≥50% 的为 0 对，最高 28.1%。**低重合率不等于不成组**，拆分型靠标题与主题判。计算重合率前须按申请号去重（A/B 文本是同一件）。

## 4 与三项判据的关系

多件相似不单独构成一项判据。它的用途是：

- 支撑手段判据（同一产品的第 N 件，从权只改一个零件）
- 支撑批次判据（同主体短时间多件围绕同一产品，说明是拆量而非研发）
- 报告中作独立说明段落，写明组内件数与产品线

## 5 边界

- 一案双申（同一申请号既有发明又有实用新型）只算 1 件
- 同主体跨产品线的多件（如一家公司同时报设备和材料）不构成组
- 关联主体判定见 `70-cross-org.md` 的聚组口径，两处口径一致
