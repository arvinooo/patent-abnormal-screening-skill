# 10 申请人：类型 / 科技属性 / 社保 / 主营匹配 / 授权发明专利

> 这一维判两件事：**主体是什么**（能不能搞研发）、**有没有研发积累**（有没有授权发明专利）。
> 五项全部可被专精特新豁免（见 `80-exemptions.md`）。

## 1a 类型（一票不过，按设立性质判，不看名称字面）

**不过**：院校（大学/学院/学校/研究所/研究院，含军队院校）、医院（含医学院校附属医院）、自然人（含个体户、家庭式组合）、文化/传媒/茶业。

- 边界：「××职业培训学校有限公司」= 企业，不是院校。
- 边界：「××电力设计院有限公司」= 有限责任公司 → 企业（虽然叫"设计院"）。
- 院校/医院在工商库查无主体是正常的，按 (71)/(73) 判类型即可。

## 1b 科技属性

**过**：高企/科技型中小企业/专精特新认定，或名称、经营范围含 科技/技术/智能/电子/软件/网络/数据/生物/医药/新材料/新能源/半导体/自动化/通信/检测/机器人/光电，或含 技术开发/技术咨询/研发/软件开发/系统集成/集成电路设计/检验检测。

**弱**：名称带"科技"但经营范围纯贸易/咨询。

**不过**：主业文化/传媒/茶业/贸易/餐饮/咨询/投资/房地产/物流，且无研发类经营范围。

## 1c 社保（T01）

| 参保人数 | 判定 |
|---|---|
| <3 | **不过**（硬判据） |
| 3–10 | 灰区：结合注册资本、实缴、名下专利数、成立年限综合看，报告写明理由 |
| ≥10 | 过 |

注意：社保是年报公示口径，可能滞后；新设未申报会显示 0/空。查无主体要区分"0 人"和"不在库"。

## 1d 主营匹配

用「本案技术对象/应用场景」× 申请人经营范围与国标行业：

| 判定 | 含义 | 举例 |
|---|---|---|
| 一致 | 就是主营产品线 | 环保设备公司报污泥脱水装置 |
| 相邻 | 同产业链上下游 / 经营范围里有对应技术服务 | 环境修复公司报风电施工设备（经营范围含"风力发电技术服务"） |
| 无关 | 无交集 | 文化传播公司报阀门结构 |

相邻判过，但要在报告里写清"相邻在哪"；无关判不过。

## 1e 授权发明专利（1.1，T02）

**何时触发**：每案都判——申请人和发明人是两个独立维度，本维不看发明人件数。

**查什么**：本案申请人**到本案申请日为止**，有没有**授权发明专利 ≥1 件**。

- 有 → 1.1 通过
- 没有 → **非正常**（申请人无研发积累）

**口径（已定）**：

| 项 | 定版 |
|---|---|
| 申请人范围 | **只认本案申请人本体**，不含母子公司/曾用名（报告标注） |
| "有授权" | **授权日（ISD）非空即算**，不问现在是否终止/失效/无效，不问是否受让取得 |
| 基准日 | **本案申请日**；本案未公开、无申请日 → 退化为查询日，报告写明 |
| 件数门槛 | ≥1 件即可 |

**检索式**（字段码见 `data-sources.md` §3）：

```text
ALL_AN:(申请人) AND PATENT_TYPE:(发明专利) AND ISD:[* TO 基准日]
```

**为什么这样判**：中国发明专利授权要 2–4 年，纯实用新型企业天然为 0。用户已确认这是有意的严格口径（就是要抓"没有发明授权却批量报实用新型"的模式），因此**不设实用新型替代、不设新公司豁免**——这一点是业务决策，不要自行放宽。

**副作用（报告里要标注）**：纯实用新型客户会全部落到"非正常"；若客户问起，这是口径决定的，不是误判。

## 1f 数据来源

- 工商四项（类型/科技属性/社保/主营）：企查查 `get_company_registration_info`，缓存 90 天，键 = 申请人全名
- 1.1 授权发明：incoPat 指令检索（浏览器，无接口费用），缓存 90 天，键 = 申请人全名
