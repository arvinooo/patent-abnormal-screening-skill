# 20 发明人：剔重名 → 计数 → 研发能力兜底（v2 核心）

> v1 只数"这个姓名今年报了几件"，同名的人混在一起必冤。v2 先把同名的人剔掉，再数。
> **1.2 只负责计数**；申请人一致性仍由 ⑤b 单独判（规则同 v1，保留原样）。

## 0 适用范围

- 只查**第一发明人**（(72) 第一位）。其余发明人不单独查（2.1 会用到他们的名字，但不检索他们名下）。
- 窗口：**滚动 12 个月** = 查询日往前推 365 天（T03）。
- 检索：`IN:(姓名) AND APD:[窗口起 TO 查询日]`，**不论发明人位次**都计入候选。
- 按**申请号**去重（A/B 文、一案双申会产生多条公开文本）。

## 1 取数（一次调用，两个用途）

每个第一发明人取一次记录集合，字段至少要有：

| 字段 | 用途 | 来源 |
|---|---|---|
| `application_number` | 去重、连接 | MCP |
| `application_date` | 窗口过滤 | MCP |
| `title` | 人工复核用 | MCP |
| `inventors` | **剔重名（共同发明人比对）** | MCP（10 积分/人） |
| `current_applicants` / `original_applicants` | 2.1 跨机构 | MCP |
| `ipc`（主分类） | **剔重名（领域比对）** | 浏览器结果表（0 积分） |

> MCP 的记录里**没有 IPC**，也不能用 `selected_fields` 指定。所以 IPC 要从浏览器检索结果表取，按 `application_number` 连接。两源都取不到 → 该案 1.2 标 `pending`。

## 2 剔重名（判"这件是不是这个人的"）

### 2.1 本案只有 1 个发明人

只能靠领域判断（没有共同发明人可比）：

```text
若 ipc(该件) 与 ipc(本案) 一致或相似 → 是同一人 → 保留
否则                                → 判重名 → 剔除
```

### 2.2 本案有多个发明人（其余发明人集合 R）

优先用身份锚，领域作为退路：

```text
若 inventors(该件) ∩ R ≠ ∅ 且 重合的名字不是常见名 → 是同一人 → 保留
否则若 ipc(该件) 与 ipc(本案) 一致或相似         → 保留（领域兜底）
否则                                            → 判重名 → 剔除
```

**常见名不作锚**：`张伟、王芳、李娜、刘洋、王伟、李伟...` 这类高频姓名出现在共同发明人里，不能证明是同一人（概率太高）。名单放 `data-sources.md` §3 的 `common_names`，可扩展。

### 2.3 领域口径

| 判定 | 规则 |
|---|---|
| 一致 | IPC 主分类**前 4 位**相同（如 `F16K5/06` 与 `F16K5/08` → `F16K`） |
| 相似 | IPC 主分类**前 3 位**（大类）相同（如 `F16K` 与 `F16D` → `F16`）… 注：前 3 位是"小类"，报告里写清是比到哪一级 |
| 不同 | 前 3 位不同 |

> 实现时统一写成"取前 N 位"参数，N 默认 4（一致）/ 3（相似），别写死字符位置。

### 2.4 第二锚（降低两个方向的误差）

| 情形 | 处理 |
|---|---|
| 该件申请人 = 本案申请人 **且** 领域一致 | 铁定同一人 → 保留 |
| 领域一致 **但** 申请人不同 | 可能同行业同名他人 → 保留但标 `pending`（待人工），不硬算进计数 |

**副作用（必须写进报告）**：同一人跨领域创新会被判重名（少计，偏松）；同行业同名者会被计入（多计，偏严）。

## 3 计数与判定

```text
N = |有效记录集合|（按申请号去重）
若 N ≥5  → 1.2 不过 → 非正常
若 N <5  → 转 1.1（rules/10-applicant.md 1e）：
            本案申请人到本案申请日有无授权发明专利
            有 → 正常；无 → 非正常
```

**这里不设"新公司豁免"和"实用新型替代"**——用户已确认严格口径是有意的。

## 4 ⑤b 申请人一致性（保留 v1 规则，不参与剔重名）

- 范围：第一发明人名下**全部年限**记录（不是 12 个月窗口）
- 判据：全部记录的 `current_applicants` 必须 = 本案申请人；任一 ≠ → 不过
- 证据分层：≥2 位本案发明人共同重合于同一异申请人 = 强证据；仅 1 人重合 = 弱证据（仍判不过，标「疑似同名碰撞，待人工复核」）
- 报告必须列出异申请人名单，供人工降级

> ⑤b 与 1.2 的分工：**1.2 判"这些记录是不是同一个人的"；⑤b 判"同一个人的记录里申请人是否一致"**。两者独立出结论，不互相覆盖。

## 5 缓存

| 命名空间 | 键 | 存什么 | 有效期 |
|---|---|---|---|
| `inventor` | 第一发明人姓名 | 原始记录（含 inventors / applicants / ipc）+ 检索式 + 取数日 | 7 天 |
| `inventor_identity` | 第一发明人 + 本案申请人 | 剔重名结果（保留/剔除清单 + 理由） | 7 天 |

派生结论（N、是否过线）**不缓存**，每次现算。

## 6 报告展示

```text
⑤ 发明人（第一发明人：林美华）
  名口径 7 件 → 剔除重名 3 件（领域不同：福州软件职业技术学院×2、国网福建电力×1）
  → 有效 4 件 <5 → 转研发能力：本案申请人到本案申请日（2025-10-16）授权发明专利 0 件 → 非正常
⑤b 一致性：名下 175 组，异申请人含 …（弱证据，建议降级）
```

## 7 已知坑

1. **公开滞后**：发明申请 18 个月才公开，12 个月窗口内的申请很多还没公开 → 计数是**下限**，方向偏松。报告标注。
2. **常见名总量溢出**：如"王猛"命中上万组 → 不要逐条拉全量，直接标"常见名，计数不可采信 → `pending`"。
3. **一案双申**：同一申请号既有发明又有实用新型文本 → 只算 1 件。
4. **本案无 IPC**（未公开、代理机构没填）→ 领域比对退化为"技术领域原文关键词"，标 `pending`。
5. **姓名带身份证号**：明细表里形如 `林美华150428199609244921`，必须先剥掉身份证号再检索；报告里显示打码版本。
