# 60 第二层：申请人（类型 / 科技属性 / 社保 / 主营匹配 / 授权发明专利）

> 这一层只判**文件之外的主体事实**：主体是什么、有没有研发积累、在几家机构报过、代理人报了多少。
> PDF 主体由第一层的两项判据判、批次由第二步判，这里只判主体事实。
> 五项全部可被专精特新豁免（见 `90-exemptions.md`）。

## 1a 类型（主体性质，按设立性质判，不看名称字面）

按设立性质判：企业、院校（大学/学院/学校/研究所/研究院，含军队院校）、医院、自然人（含个体户、家庭式组合）。下列情形成立，成立即非正常：

| 主体性质 | 成立条件 |
|---|---|
| 自然人 / 个体户 | 成立 |
| 文化 / 传媒 / 茶业类公司 | 主营业务与技术主题无交集 |
| 院校 / 医院 / 研究所 | 不成立，只记背景 |

院校、医院、研究所不因身份命中——第一层两项全中的案子已在第一层判非正常，不会进到本层。已判定正常的 33 件中 25 件申请人为院校/院所/政府机构，按"院校一票不过"会误杀 76%。

- 边界：「××职业培训学校有限公司」= 企业，不是院校。
- 边界：「××电力设计院有限公司」= 有限责任公司 → 企业（虽然叫"设计院"）。
- 院校/医院在工商库查无主体是正常的，按 (71)/(73) 判类型即可。

## 1b 科技属性

**过**：高企/科技型中小企业/专精特新认定，或名称、经营范围含 科技/技术/智能/电子/软件/网络/数据/生物/医药/新材料/新能源/半导体/自动化/通信/检测/机器人/光电，或含 技术开发/技术咨询/研发/软件开发/系统集成/集成电路设计/检验检测。

**弱**：名称带"科技"但经营范围纯贸易/咨询。

**不过**：主业文化/传媒/茶业/贸易/餐饮/咨询/投资/房地产/物流，且无研发类经营范围。

## 1c 社保

```text
参保人数 <3  → 成立（一票否决）
3–10         → 灰区，只记背景
≥10          → 不成立
```

取数：企查查 `get_company_registration_info` 的参保人数，缓存 90 天。

注意：社保是年报公示口径，可能滞后；新设未申报会显示 0 或空。查无主体要区分"0 人"和"不在库"——"0 人"按成立记，"不在库"记数据缺失。

标定：已判定非正常的 16 家中参保 <3 的 4 家（25%）；已判定正常的 6 家中 2 家（33%）。正常侧占比高于非正常侧，本项是误判风险最高的一项，输出结论时附复核提示。

## 1d 主营匹配

用「本案技术对象/应用场景」× 申请人经营范围与国标行业：

| 判定 | 含义 | 举例 |
|---|---|---|
| 一致 | 就是主营产品线 | 环保设备公司报污泥脱水装置 |
| 相邻 | 同产业链上下游 / 经营范围里有对应技术服务 | 环境修复公司报风电施工设备（经营范围含"风力发电技术服务"） |
| 无关 | 无交集 | 文化传播公司报阀门结构 |

相邻判过，但要在报告里写清"相邻在哪"；无关判不过。院校、医院的技术方向常超出经营范围，本项对其不适用。

## 1e 授权发明专利（T23）

**何时触发**：每案都判——申请人和发明人是两个独立维度，本项不看发明人件数。

**查什么**：本案申请人**到本案申请日为止**，有没有**授权发明专利 ≥1 件**。

- 有 → 本项不触发；**不等于放行**，继续按其余项判
- 没有（且申请人为企业） → **非正常**（申请人无研发积累）

标定来源：16 家已判定非正常的申请人中 11 家有授权发明（最高 61 件），仅 5 家为 0；6 家已判定正常的主体中 1 家为 0。本项是必要条件，不是充分条件。

**口径（已定）**：

| 项 | 定版 |
|---|---|
| 申请人范围 | **只认本案申请人本体**，不含母子公司/曾用名（报告标注） |
| "有授权" | **结果页「发明授权」类型统计 ≥1 即算**，不问现在是否终止/失效/无效，不问是否受让取得 |
| 基准日 | **本案申请日**；本案未公开、无申请日 → 退化为查询日，报告写明 |
| 件数门槛 | ≥1 件即可 |

**检索式**（字段码见 `data-sources.md` §8）：

```text
AP=(申请人) AND AD=[19850101 TO 基准日]
```

结果页左侧按类型分组，「发明授权(N)」一栏即授权发明文本数；该栏缺失表示 0 件。

**为什么这样判**：中国发明专利授权要 2–4 年，纯实用新型企业天然为 0。用户已确认这是有意的严格口径（就是要抓"没有发明授权却批量报实用新型"的模式），因此**不设实用新型替代、不设新公司豁免**——这一点是业务决策，不要自行放宽。

**副作用（报告里要标注）**：纯实用新型客户会全部落到"非正常"；若客户问起，这是口径决定的，不是误判。

## 1f 数据来源

- 工商四项（类型/科技属性/社保/主营）：企查查 `get_company_registration_info`，缓存 90 天，键 = 申请人全名
- 1e 授权发明：incoPat 指令检索（浏览器，无接口费用），缓存 90 天，键 = 申请人全名

## 1g 研发过程记录

列为可疑的案件，可要求申请人提供研发记录、设计图纸、实验记录、检测报告。无法提供的，认定非正常。

这一项是补充核查，不是自动取数项；在前八项都取不到、或主体事实与文本明显不符时才用。要求材料与回复过程记入 `cases/*.json`，报告只写"未能提供研发过程记录"。
