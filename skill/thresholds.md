# 阈值总表（唯一出口）

> 改阈值只改这里。`scripts/` 里的常量、各模块文档一律引用本表，不重复写数字。
> 每批的阈值快照写进该批的 `_batch.json` 的 `rules_version`；报告正文不印快照。

## 方向记号怎么读

| 记号 | 意思 |
|---|---|
| 判硬 | 单独命中就定非正常，不用别的证据 |
| 判软 | 单独命中只记存疑，要和 T11 同时成立才定案 |
| 筛 | 不作结论，只决定要不要继续查 |
| 救 | 命中即证明清白，撤掉其他判据 |

## 结论规则

```text
第一层 文本（只读 PDF 正文；同批 ≥2 件时加跨案，0 查询）
  硬证据：T04、T08 单独成立                     → 非正常
  跨案：T13 拆分型、T14 复制型 成立              → 非正常（一票否决）
  软证据 + T11 同时成立                         → 非正常
  单一软证据、单一 T11、仅引用在先文献            → 存疑，进第二层
  无任何命中                                    → 正常，不核主体

第二层 主体（只跑第一层存疑案）
  前置：查专精特新；国家级小巨人、省级专精特新 → T23–T27 跳过，不取数、不否决
  任一项主体事实成立                            → 非正常
  全不成立                                      → 正常
  数据取不到                                    → 待核
```

T11 放行：有性能测试表或有测试结果数值视为有验证结构，按正常；仅背景技术引用在先文献、无表无数的记存疑（证据不足，交主体步）；机械类已记载工程参数 ≥3 处、实用新型同样豁免。
实用新型不适用第十六条，只按手段判：硬证据 → 非正常，软证据 → 存疑进第二层。

实测依据见 `references/ordering.md`：硬判只留第十二条与第十条时精确率 94%，加入第九条第一项降到 92%，再加入第十一条第一项降到 89%；护栏用"引用在先文献"比用"实施例≥2 且参数≥25"精确高 0.4 点、召回高 1 点。

## 第一层·跨案判据

同批送审 ≥2 件才判，按申请人成组；成组口径、判例、重合率算法见 `stage1-text/cross-case.md`。

| 编号 | 维度 | 阈值 | 方向 | 实测 |
|---|---|---|---|---|
| T13 | 拆分型 | 同申请人 ≥2 件、申请日跨度 ≤12 个月，组内发明名称全部围绕同一产品/设备 | **判硬（一票否决）** | 判例 2 组构成 / 1 组不构成 |
| T14 | 复制型 | 20 字片段重合率 ≥50%，技术问题与原理一致、差异仅参数 | **判硬（一票否决）** | 103 对同主体配对上 0 对命中，最高 28.1% |

T13 成立时组内各件均判非正常，报告写组内件数、产品线、申请日跨度。T14 成立时两件均判非正常。单件送审记"未核（单件）"，不算命中。

## 第二层·主体八项

只判**文件之外的主体事实**，只跑第一层存疑案。每项都要"身份 + 事实"。

**定案规则**：进入第二层的案子第一层已有文本命中，因此**任一项成立即判非正常**；全不成立 → 正常；数据取不到 → 待核。

**专精特新豁免**：先查资质（`qcc operation get_honor_info`）。命中"专精特新小巨人"（国家级）或"专精特新中小企业"（省级）的，T23–T27 全部跳过——不取数、不参与否决，报告保留原判定并注明"企业资质项因专精特新豁免"。T20、T21、T22 不受豁免。

| 编号 | 项 | 成立条件 | 方向 | 专精特新豁免 | 窗口 | 键数（446 件） | 数据源 |
|---|---|---|---|---|---|---|---|
| T20 | 发明人有效件数 | 剔重名后 ≥5 件 | 判 | 否 | 本案申请日往前 12 个月 | 295 发明人 | incoPat |
| T21 | 跨机构组数 | 聚组后 ≥3 组 | 判 | 否 | 同上 | 0 额外（复用） | incoPat + 企查查 |
| T22 | 代理师代理量 | ≥300 件；查无此人记待核 | 判 | 否 | 同 T20 | 44 代理师 | 香橼树（本所口径） |

院校、医院不因身份命中：已确认正常样本的申请人中占 55%、非正常样本中占 2%。

T20–T27 的命中率在 446 件语料上无法标定：正例全部来自 2 家机构、反例全部来自客户自有机构，主体事实与标签共线。键数用于估成本，不用于判优先级。

## 边界值速查

| 情形 | 判定 |
|---|---|
| 硬证据（T08、T04）单独成立 | 非正常 |
| 拆分型、复制型成立 | 非正常（一票否决） |
| 软证据 + T11 同时成立 | 非正常 |
| 只有软证据，或只有 T11 | 存疑，进第二层 |
| 无任何文本命中 | 正常，不核主体 |
| 单件送审 | 跨案未核（单件），不构成命中 |
| 实用新型：任意 | 只判手段；硬证据记非正常，软证据记存疑，不放行 |
| 主体步任一项成立 | 非正常 |
| 专精特新（国家级小巨人 / 省级） | T23–T27 跳过，T20–T22 照常 |
| 发明人有效件数 = 5 | 命中（≥5 挂） |
| 跨机构组数 = 2 / = 3 | 2 不命中；3 查关联，无关联则命中 |
| ①社保 <3 | 本项成立 |
| 结构案触发 T08 | 出结论但附"核对附图"提示，须复核后再定 |
| 机械类已记载工程参数 ≥3 处 | 不因缺实验数据认定 |
| 数据拿不到 | 待核，不默认通过，不凭空判不过 |

## 窗口锚点

所有"12 个月"从**本案申请日**往前推；本案无申请日则用查询日。报告必须写明锚点。
