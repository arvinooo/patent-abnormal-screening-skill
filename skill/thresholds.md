# 阈值总表（唯一出口）

> 改阈值只改这里。`scripts/` 里的常量、各模块文档一律引用本表，不重复写数字。
> 每批的阈值快照写进 `references/cases.md` 的 `_batch.json` 的 `rules_version`；报告正文不印快照。

## 结论规则

```text
第一阶段（只读 PDF 正文）：
  任一手段判据成立，或第十六条有益效果段复述成立 → 非正常
  无手段判据，且满足放行条件 → 正常
  其余 → 存疑，进第二阶段

第二阶段（只对存疑案，先批次后主体）：
  任一项成立 → 非正常
  全不成立 → 正常
  数据缺失、灰区、查无此人 → 待核
```

放行条件：编号实施例 ≥2 且（有性能测试表 或 说明书带单位参数 ≥25 处）。实用新型不适用，全部列存疑。

## 第二阶段：主体八项

只判**文件之外的主体事实**。任一成立即非正常；全不成立即正常。每项都要"身份 + 事实"。

| 编号 | 项 | 成立条件 | 窗口 | 数据源 |
|---|---|---|---|---|
| T20 | 发明人有效件数 | 剔重名后 ≥5 件 | 本案申请日往前 12 个月 | incoPat |
| T21 | 跨机构组数 | 聚组后 ≥3 组 | 同上 | incoPat + 企查查 |
| T22 | 代理师代理量 | ≥300 件；查无此人记待核 | 同 T20 | 香橼树（本所口径） |
| T23 | 授权发明专利 | 0 件且申请人为企业；院校/院所/医院/自然人不适用 | 到本案申请日 | incoPat |
| T24 | ①类型 | 自然人/个体户；或文化/传媒/茶业类且主营无交集 | — | 申请人栏 |
| T25 | ①科技属性 | 主业文化/传媒/茶业/贸易/餐饮/咨询/投资/房地产/物流，且无研发类经营范围 | — | 企查查 |
| T26 | ①社保人数 | 参保 <3 | 取数日 | 企查查 |
| T27 | ①主营匹配 | 与技术对象无关，且非院校非医院 | — | 企查查 |

院校、医院不因身份命中：已确认正常样本的申请人中占 55%、非正常样本中占 2%。

## 边界值速查

| 情形 | 判定 |
|---|---|
| 发明：手段命中 | 非正常（第一阶段即定） |
| 手段未命中 + 满足放行条件 | 正常（第一阶段即定） |
| 手段未命中 + 不满足放行条件 | 存疑，进第二阶段 |
| 实用新型：任意 | 只判手段；命中记非正常，未命中记存疑，不放行 |
| 第二阶段任一项成立 | 非正常 |
| B01 数据拿不到 | 未核，不得记为不成立 |
| 发明人有效件数 = 5 | 命中（≥5 挂） |
| 跨机构组数 = 2 / = 3 | 2 不命中；3 查关联，无关联则命中 |
| ①社保 <3 | 成立（一票否决） |
| 结构案触发 T08 | 出结论但附"核对附图"提示，须复核后再定 |
| 机械类已记载工程参数 ≥3 处 | 不因缺实验数据认定 |
| 数据拿不到 | 待核，不默认通过，不凭空判不过 |

## 窗口锚点

所有"12 个月"从**本案申请日**往前推；本案无申请日则用查询日。报告必须写明锚点。
