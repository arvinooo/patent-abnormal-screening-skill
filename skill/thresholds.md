# 阈值总表（唯一出口）

> 改阈值只改这里。`scripts/` 里的常量、各模块文档一律引用本表，不重复写数字。
> 每批的阈值快照写进批次的 `_batch.json` 的 `rules_version`；报告正文不印快照。

## 结论规则

```text
第 0 步 批次 B01、B02（每机构 1 次查询，先于文本）
       命中 → 非正常（整批定案，无其他判据可推翻）

第 1 步 文本（只读 PDF 正文，0 查询）
       硬证据：第十二条、第十条单独成立            → 非正常
       软证据：其余手段条款 + 第十六条同时成立      → 非正常
       单一软证据、单一第十六条、仅引用在先文献      → 存疑
       无任何命中                                  → 正常（批次未命中该机构的，须跑 T23/T25/T26 才能落正常）

       主体维度不单独定案：需 ≥2 项同时成立，或 1 项成立且文本步至少一条命中，才定非正常；
       只有 1 项、文本又无命中的，记存疑。批次 B01/B02 除外，保持单独定案。

第 2 步 主体八项（只对存疑案）
       任一项成立 → 非正常；能证明清白 → 正常；数据缺失 → 待核
```

T11 放行：有性能测试表或有测试结果数值视为有验证结构，按正常；仅背景技术引用在先文献、无表无数的记存疑（证据不足，交主体步）；机械类已记载工程参数 ≥3 处、实用新型同样豁免。
实用新型不适用第十六条，只按手段判：硬证据 → 非正常，软证据 → 存疑。

实测依据见 `references/ordering.md`：硬判只留第十二条与第十条时精确率 94%，加入第九条第一项降到 92%，再加入第十一条第一项降到 89%；护栏用"引用在先文献"比用"实施例≥2 且参数≥25"精确高 0.4 点、召回高 1 点。

## 主体八项（第 2 步）

只判**文件之外的主体事实**。每项都要"身份 + 事实"。

**定案规则**：主体维度依赖外部平台数据，是间接证据，不单独定案。需同时满足下列之一：

- 主体项 ≥2 项成立（例：社保 <3 且无授权发明）；
- 主体项 1 项成立，且文本步对该案至少有一条命中（软证据或第十六条）。

只有 1 项成立、文本步又无命中的，记存疑，交人工复核。理由：社保、发明人件数这类事实单独看都有正常解释（新设公司未申报、团队本就高产），2026-10-31 批实测按一票否决会把 67 件里的大多数都判成非正常，与"文本无异常"的判断冲突。

批次 B01/B02 不在此列：批次判据实测零误伤，保持单独定案。

## 边界值速查

| 情形 | 判定 |
|---|---|
| 批次 B01 命中 | 非正常（整批，先于一切文本判据） |
| 硬证据（第十二条、第十条）单独成立 | 非正常 |
| 软证据 + 第十六条同时成立 | 非正常 |
| 只有软证据，或只有第十六条 | 存疑，进主体步 |
| 无任何文本命中 | 正常 |
| 实用新型：任意 | 只判手段；硬证据记非正常，软证据记存疑，不放行 |
| 主体步任一项成立 | 非正常 |
| B01 数据拿不到 | 未核，不得记为不成立 |
| 发明人有效件数 = 5 | 命中（≥5 挂） |
| 跨机构组数 = 2 / = 3 | 2 不命中；3 查关联，无关联则命中 |
| ①社保 <3 | 成立（一票否决） |
| 结构案触发 T08 | 出结论但附"核对附图"提示，须复核后再定 |
| 机械类已记载工程参数 ≥3 处 | 不因缺实验数据认定 |
| 数据拿不到 | 待核，不默认通过，不凭空判不过 |
