## 1. ① 申请人

### 1a. 类型定义（《规则细化》第 1 节原文）

**院校**：我国境内，经教育行政部门（教育部及地方各级教育局）**或其他主管部门（如人社部门、军队系统）**审批/备案设立，以开展教育教学、人才培养或者科学研究为核心职能，面向特定人群实施有组织、有计划教育活动的各类教育机构的统称，是"学校""科研院所"的规范统称，包含各级各类所有学校，包括学前教育、义务教育、高中阶段教育、高等教育、特殊教育、专门教育、**研究所、研究院**等。

**医院**：境内经卫生健康行政部门审批登记、取得《医疗机构执业许可证》，主要承担疾病诊治，开展急诊急救、手术、住院治疗、康复护理，同时可开展医学教学、科研、基层业务指导的医疗机构；包含公立、民营、中外合资合作等所有登记为"医院"类别的机构，**医学院校附属医院纳入医院范围**。

**自然人**：申请人为个人姓名（含家庭式发明人组合、个体户）。

**非科技行业**：文化、传媒、茶业（现行三类，后续补充）——名称/经营范围以这些为主。

判定顺序：先看是否医院 → 再看是否企业 → 再看科研院所 → 最后院校。

边界只看**设立性质**：
| 名称 | 判定 | 来源 |
|---|---|---|
| 中国人民解放军海军军医大学 | 军队系统设立的院校 → ①不过 | 案 B |
| 陆建收 | 自然人 → ①不过 | 案 D |
| ××大学××附属医院 | 医院 | 规则原文 |
| ××职业培训学校有限公司 | 企业（不是院校） | 用户口径 |
| 贵州省材料产业技术研究院 / 天津市药品检验研究院 | 研究院 → ①不过 | 本批实测 |

### 1b. 科技属性

**强（任一即过）**：高企证书 / 科技型中小企业入库 / 专精特新；名称含 科技、技术、信息技术、智能、电子、软件、网络、数据、生物、医药、新材料、新能源、智能制造、半导体、通信、自动化、机器人、光电、检测；经营范围含 技术开发、技术咨询、技术服务、技术转让、研发、软件开发、系统集成、集成电路设计、检验检测；主营属技术密集型（有专利群/软著/研发投入）。

**弱**：名称带"科技"但经营范围纯贸易/咨询。

**无 → 不过**：名称与经营范围均以文化、传媒、广告、茶业、贸易、商贸、餐饮、食品、咨询、投资、房地产、劳务、物流、种植养殖为主，无研发类经营范围。

### 1c. 社保

取企查查「参保人数」或天眼查 `socialStaffNum`（口径一致）。
- **<3 → ①不过**
- 3–10：结合企业规模（微型加重）、研发实力、申请历史
- ≥10：过
- 查无主体：院校/医院属正常（不在工商库）；企业查无 → 「待核查」，不得臆断
- 参保是年报公示口径，可能滞后或新设未申报为 0 —— 报告写"公示值 + 查询日期"

### 1d. 主营匹配

输入：PDF 的技术对象/应用场景/技术领域 vs `经营范围` + `企业简介` + `行业` + `企业标签`。

| 档 | 判法 | 结论 |
|---|---|---|
| 一致 | 技术对象属主营产品线 | 过（案A 华为-智能交通、案C 大疆-影像、案E 小米-家电） |
| 相邻 | 同一产业链上下游（磨煤机改造公司 - 磨煤机出力计算） | 过，写明理由 |
| 无关 | 与经营范围无交集（茶业公司申请无人机算法） | **不过** |

辅助线索（非必需）：微型企业 + 社保 <10 → 疑无研发团队；发明专利数畸高但社保极低 → 批量申请嫌疑。

> 申请人行业匹配**不构成豁免**：军医大 × 野战医疗再匹配，仍按院校类型一票定案（案 B）。

## 2. ② 代理公司

**判据：代理师当年（1/1–取数日）累计代理量 >500 件/人 → ②不过，且连坐该机构代理的本案。**

- 口径：申请日落在当年窗口、代理师=目标人的案卷数
- 平台不可用 / 无登录态且人工未登录 / 代理师属其他所不可见 → 标「未核」，不默认通过也不凭空判不过
- 报告必须写取数区间与日期

机构层面两项不判：
- **非正常申请预警 / 重点监控名单**：国知局该名单为系统内网通报，不对外公开，无法获得完整名单。公开的行政处罚决定书只是零星个案，可作旁证，不作为通过依据。
- **机构申请量短期波动**：无既定阈值。

## 3. ③ 技术领域

### 清单定义（《规则细化》第 2 节）

- **机械装置**：纯机械结构/装置，无电气、控制或材料创新
- **生活类发明创造**：日用品、生活小工具、家居小改
- **计算机算法**：纯计算方法/数学模型，无具体应用系统与工程手段
- **方法步骤图的系统**：纯流程/步骤图，无装置或技术手段支撑

### 三问（全"否"才判过）

1. 权1 有没有承载技术效果的物理结构或工程手段？
2. 去掉计算/步骤，还剩什么实质内容？
3. 技术效果是不是各特征效果简单相加、无协同？

### 边界判例

| 案 | 特征 | 判定 |
|---|---|---|
| 小米冰箱风道组件（案E） | 明确解决冷气分布不均/凝露，有结构-效果链 | 过（不因"机械"判不过） |
| 康盛宏达 磨煤机出力计算（案F） | 纯计算方法，无应用系统与工程手段 | ③不过 |
| 深圳闪联 相对指针输入校验系统 | 纯软件模块组合，模块各自独立发挥作用 | ③不过 |
| 上海熙软 成本数据降维存储 | 纯算法 + 存储步骤，无工程手段 | ③不过 |
| 天津娜绮林 节能型道路监控装置 | 机械装置，无超出常理的改进链 | ③不过 |

判定看 PDF 技术领域原文，**不是 IPC 号机械套用**。

## 4. ④ 撰写

《规则细化》第 3 节：保护范围与说明书记载的发明内容相比，若权利要求比可受保护的内容小得多，即为过窄。原文列了五种表现，现行口径只保留两条：

1. **缺多级布局**（原文"缺多级布局，独立权利要求就过窄，从属权利要求没有逐层收窄的空间，没有'宽→窄'的层级"）
2. **方法步骤顺序/参数范围限定过死**（原文"限定不必要的方法步骤顺序或具体参数范围"）

原文另三种（写入非必要特征 / 下位概念锁定 / 封闭式表述"由…组成"）**已不单列**，若明显到影响保护范围，可作为④第 1 条的佐证写进证据，不作为独立判据。

「简单堆叠」原文（特征并列拼凑、无功能相互支持、效果简单相加）归入 ③ 第 3 问。

## 5. ⑤ 发明人

### 5a. 当年件数（>5 不过）

**"当年" = 检索当天的年份的 1 月 1 日 → 查询当日**，按申请日落窗口；跨年自动顺延，检索式和代码里不写死年份。

**口径**：检索该姓名，**不论排第几发明人，当年申请的都要算**，按申请号去重计件；**>5 不过（=5 通过）**。

- 检索式：`IN:(姓名) AND APD:[YYYY0101 TO 今天]`
- `F_IN` 只含第一发明人，会漏掉该姓名作为共同发明人的申请，不用于本判定
- 计数：剥序号 → 按 `application_number` 去重（A/B 文、一案双申会虚高，raw total 不能直接当件数）
- 截断（如常见名 total 数千）时，去重件数只是下限，报告标注

```python
import re
def strip_no(s): return re.sub(r"^\d+[\.、]\s*", "", s or "")

def count_apps_any_position(name, records, year):
    apps = set()
    for r in records:
        invs = [strip_no(s) for s in r.get("inventors", [])]
        if name not in invs:                        # 不论位次，出现即计入
            continue
        if not str(r.get("application_date", "")).startswith(str(year)):
            continue                                # 当年窗口
        apps.add(r.get("application_number"))       # 按申请号去重
    return len(apps)
```

### 5b. 申请人一致性

- 范围：**本案第一发明人**（(72) 第一位）。PDF 有多个发明人时只查第一位，其余发明人不查、不计成本。
- 5a 和 5b 共用这一次检索结果（`IN:(姓名)` 一次调用）
- 判据：该第一发明人名下**全部**检索记录的 `current_applicants`/`original_applicants` 必须全部 = 本案申请人
- 任一 ≠ → 不过

**证据分层**

| 层 | 条件 | 处理 |
|---|---|---|
| 强 | ≥2 位本案发明人共同重合于同一异申请人 | 直接判不过，排除同名碰撞 |
| 弱 | 仅 1 人重合 | 仍判不过，标「疑似同名碰撞，待人工复核」 |
| 关联提示 | 异申请人与本案申请人名称互相包含或 ≥6 字共同前缀 | 单独标注（集团/曾用名嫌疑），人工可澄清后降级 |

**已知误伤源（必须在报告里列名单）**
- 母子公司分流：国盾量子 → 山东国迅量子芯；正常研发主体变更会被判挂
- 同名碰撞：陶俊 6004 篇 / 138 家，孙志 54751 篇；常见名（单人挂 ≥20 家申请人）标「常见名」，复核优先级最高但**不影响判不过**

**公开滞后**：发明申请自申请日起 18 个月公开。当年计数是**下限**，口径偏放过（漏检多、误杀少）。越近年末越准。报告【复核】栏标注。

**溢出**：某发明人 `total > 1000` → records 只是样本，不能完整枚举：5a 改用当年窗口检索，5b 改用 `NOT ALL_AN:(本案申请人)` 反查。

## 6. ⑥ 多件相似申请

### 成组（不成立就不判）

- 同一申请人或关联主体 **≥2 件** + **12 个月内**
- 关联主体并组：须其自身 ≥2 件，或有股权/实控人证据
- 组内每件都要有 PDF（缺 PDF 的成员不并入，报告注明）
- **只有 1 件的主体不构成组**，按各维单案判，不得为凑组并入邻组

### 型A 复制型

正文 20 字 shingle 重合率 ≥50%，且技术问题/原理一致、差异仅参数 → 「内容明显相同」。

```python
def shingles(text, k=20):
    t = "".join(text.split())
    return {t[i:i+k] for i in range(len(t) - k + 1)}
def overlap(a, b, k=20):
    return len(shingles(a, k) & shingles(b, k)) / max(1, len(shingles(a, k)))
```

实测提醒：拆分型案件的文本重合率可以极低（芯烨 5 件仅 5.6%–7.3%），**低重合率不等于不成组**，型B 靠标题/主题判。

### 型B 拆分型

判据只一条：组内各件发明名称**全部围绕同一产品/设备**（产品级尺度）。
- 同一产品的结构件、控制方法、装配工艺、配套方法 → 都算同主题
- 组内跨多类设备（硫化机 + 输送线 + 模具）→ **整组不构成**，不做子组拆分
- 「产线级也算」待用户拍板，默认按产品级不构成

### 判例

| 组 | 概况 | 判定 |
|---|---|---|
| 珠海芯烨 9 件（69 天） | 打印机结构/控制方法/切刀/散热/装配工艺/蓝牙打印/图片裁剪 | 型B |
| 贵州轮胎 9 件（12 个月） | 硫化机、输送线、组合模具、管道检测 | 不构成 |
| 捷莱弗 4 件（6 个月） | 微流控清洗/喷墨补偿/打印数据生成/移液控制，同一 DNA 合成设备 | 型B |
| 汇瑞森 2 件 | 牙周塞治剂 / 骨修复材料，不同产品 | 不构成 |
| 贵州亚芯 2 件 | 塑封设备 / 溢胶清除设备，同一封装产线两台不同设备 | 边界：默认不构成 |
| 珠海恒盛 1 件 | 打印机，与芯烨同领域但单件 | 不构成组 |

## 7. 违法 / 公德 / 公共利益（《规则细化》第 2 节）

1. **违反法律**：发明创造本身的目的违反法律，直接以违法为目的。例：用于赌博的设备、机器或工具；吸毒的器具；伪造货币、票据、公文、证件、印章、文物的设备。
2. **违反社会公德**：与社会公众普遍接受的伦理道德观念相悖，有伤风化、损害社会和谐稳定。例：带有凶杀、淫秽内容或暴力恐怖、违反基本人伦。2023 年修改后外观设计增加"带有低俗内容"。
3. **妨害公共利益**：实施或使用可能给公众或社会造成危害，或使正常社会秩序受影响。例：严重污染环境、破坏生态平衡、危害公共安全、损害国家利益；涉及"政党的象征和标志"；外观设计含中国国旗、国徽。

命中 → 非正常（任何申请人）。

## 8. 77号令第三条八项 ↔ 本判定法

| 条款 | 情形 | 单份 PDF 可判性 | 对应维度 |
|---|---|---|---|
| (一) | 多件申请内容明显相同 / 特征要素简单组合 | ✗ 需跨案 | ⑥ 型A |
| (二) | 编造伪造内容、数据、效果；抄袭、简单替换、拼凑 | 部分（编造/效果可查） | ③ + 人工复核 |
| (三) | 主要为计算机技术等随机生成 | ✓ | ③ |
| (四) | 明显不符合技术改进/设计常理；变劣、堆砌、非必要缩限 | **✓ 重点** | ③④ |
| (五) | 无实际研发活动提交多件申请 | ✗ 需外部 | ①社保/规模、⑤a |
| (六) | 恶意分散、先后、异地提出 | ✗ 需跨库 | ⑥ 型B |
| (七) | 不正当转让受让 / 虚假变更发明人 | ✗ 需跨库 | ⑤b |
| (八) | 其他违反诚实信用 | 兜底 | — |

其他条款：第二条（诚实信用、以真实发明创造活动为基础）；第四条（代理机构连带责任）；第九条（不予减缴、公告纳入信用平台、严重违法失信名单、统计扣除、追还资助奖励）。

## 9. 查新检索

申请前/申请中在全球现有技术范围内检索相同或相近文献，判断新颖性/创造性。实践中按语义检索排序，**相似度 ≥80% 需关注**。
可用库：黑马、智慧芽、水豚知产（规则细化第 5 节）。无 MCP → 标「未核查」，不作判据，只进【复核】。
