# T21 跨机构申请

> 判什么：这个第一发明人在 12 个月内，是不是**在多家互不相关的机构名下**报专利——一个人替好几家公司批量报。
> 对象是**人**，不是单件案子。第二层一票否决：判不合格，该人在本批负责的案子全部命中。

## 0 先看缓存

`facts` 里已有 `T20|第一发明人|窗口` 且 `org_groups` 不为空 → 直接用组数，不重跑聚组；为空才按下面流程算，算完写回同一键。

## 1 流程

```text
① 取集合 S = S1-inventor.md 第 2 步剔重名后的有效记录（不重新检索）
② 从 S 收集申请人（去重）
   只有本案申请人 1 家 → 不适用，记为"1 组"
   2 家及以上 → 进入③
③ 按关联关系把机构聚成组（并查集 / 传递闭包）
④ 组数 1–2 → 不命中
   组数 ≥3 → 命中
```

先聚组再数的原因：母公司报、子公司也报，机构名好几个但其实是同一集团，不该算跨机构。

## 2 关联关系（五条，任一成立即关联）

| 依据 | 说明 |
|---|---|
| 同法定代表人 | 两家公司法定代表人为同一自然人 |
| 同注册地址 | 归一化后字符串一致 |
| 同字号 | 名称去掉行政区划、行业词、组织形式后，字号相同或互相包含（"小米科技（武汉）""北京小米移动软件"→ 字号都是"小米"） |
| 名称互相包含 / ≥6 字共同前缀 | "中国电建集团湖北工程"与"中国电建集团河南工程" |
| 同一件申请的共同申请人 | 同一申请号下同时列名的几家，视为同一申报组合 |
| 自然人 ↔ 其任法定代表人的公司 | 申请人里有自然人，且该姓名等于另一申请人的法定代表人 |

字号取法：删除括号内容、组织形式（有限公司／股份有限公司／集团／控股）、行政区划（北京／上海／武汉／深圳／中国……）、行业词（科技／智能／电子／信息／网络／材料／环保／工程／建设／实业／投资……），剩下即字号；不足 2 字不作为依据。

传递闭包：A 与 B 同法人、B 与 C 同住所 → A/B/C 算一组。

## 3 判定

| 情形 | 判定 |
|---|---|
| 剔重名后只有本案 1 家 | 不命中（记"1 组"） |
| 聚组后 1–2 组 | 不命中 |
| 聚组后 ≥3 组 | 命中 |
| 第一发明人是常见名（名下 >1000 组） | 待核（机构数不可采信，报告写"姓名太常见，机构组数无法确认"） |

允许 2 家（本案 + 1 家）：母公司报一份、子公司报一份，公司报 + 老板个人报，都不算跨机构。

## 4 取数

企查查 `get_company_registration_info` 取法定代表人 + 注册地址，缓存 90 天；同一法定代表人只查一次。自然人申请人不需要查工商。

## 5 报告写法

```text
- 原因：本案申请日往前 12 个月内的记录涉及 3 个互不相关的申报组合（该公司、另两家无关联企业），符合一人多主体批量申报。
```
