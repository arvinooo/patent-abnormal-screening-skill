# S4 授权发明专利（T23）

> 人话版：一家企业到申请日为止一件发明专利都没授权过，说明没有研发积累，却在批量报案子。
> 八项一票否决：任一项成立即非正常（见 `thresholds.md` 第二层定案规则）。本项属企业资质，申请人命中专精特新时整项跳过、不取数（见 `S7-exemptions.md`）。
> 判：本案申请人到本案申请日为止，有没有授权发明专利。0 件且为企业 → 本项成立。
> 数据来源见 `references/data-sources.md`；缓存 90 天，键 = 申请人全名。

## 1e 授权发明专利（T23）

**何时触发**：每案都判——申请人和发明人是两个独立维度，本项不看发明人件数。

**查什么**：本案申请人**到本案申请日为止**，有没有**授权发明专利 ≥1 件**。

- 有 ≥2 件 → 本项不触发；**不等于放行**，继续按其余项判
- 恰好 1 件 → 核对这 1 件的 **申请人(原始)** 与 **当前权利人**：
  - 两者都是本案申请人 → 本项不触发
  - 不一致（受让取得、已转出） → **本项成立**，报告写“唯一一件授权发明（公开号 X）的当前权利人已不是申请人”
  - 核对没返回 → 待核，写“唯一一件授权发明的权利人未核”
- 没有（且申请人为企业） → **本项成立**（申请人无研发积累）

标定来源：16 家已判定非正常的申请人中 11 家有授权发明（最高 61 件），仅 5 家为 0；6 家已判定正常的主体中 1 家为 0。本项成立即命中；有授权也不等于放行，其余项照常判。

**口径（已定）**：

| 项 | 定版 |
|---|---|
| 申请人范围 | **只认本案申请人本体**，不含母子公司/曾用名（报告标注） |
| "有授权" | **结果页「发明授权」类型统计 ≥1 即算**，不问现在是否终止/失效/无效，不问是否受让取得 |
| 基准日 | **本案申请日**；本案未公开、无申请日 → 退化为查询日，报告写明 |
| 件数门槛 | ≥1 件即可 |

**批量取数**（10 家一条检索式，比逐家单查快约 2 倍；口径相同）：

```bash
python3 scripts/inco_granted.py --json apps.json     # [{"applicant":"…","base_date":"2025-08-14"}, …]
```

**单件核对检索式**（字段码见 `data-sources.md` §8）：

```text
PN=(公开号) AND AP-OR=(申请人) AND PATENTEE=(申请人)   # 命中 ≥1 即同一主体
```

**检索式**（字段码见 `data-sources.md` §8）：

```text
AP=(申请人) AND AD=[19850101 TO 基准日]
```

结果页左侧按类型分组，「发明授权(N)」一栏即授权发明文本数；该栏缺失表示 0 件。

**为什么这样判**：中国发明专利授权要 2–4 年，纯实用新型企业天然为 0。用户已确认这是有意的严格口径（就是要抓"没有发明授权却批量报实用新型"的模式），因此**不设实用新型替代、不设新公司豁免**——这一点是业务决策，不要自行放宽。

**副作用（报告里要标注）**：纯实用新型客户会大量落到本项成立；若客户问起，这是口径决定的，不是误判。
