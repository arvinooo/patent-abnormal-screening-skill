# 专利非正常申请筛查

## 一、这套东西在判什么

一句话：**这件专利是为了保护技术，还是为了凑数。**

凑数的案子有两个共同点，逐个查：

| 线索 | 大白话 | 怎么看 |
|---|---|---|
| 文本 | 这件案子写没写出"怎么做、凭什么有效" | 读权 1 和说明书，看有没有具体手段和验证数据 |
| 主体 | 申请人、发明人像不像真在做这件事 | 查工商、查授权发明、查发明人名下件数 |

先读文本（0 成本，但只够出"存疑"），再查主体（最贵，只查存疑的）；多件送审时加一步跨案核对，看是不是把一件产品拆成多件申请。

## 二、一件案子走一遍

真实案例：`CN120777670A 地源热泵系统的安全监测方法及装置`，申请人北京华清洁能。

**① 读首页**——代理机构「北京云嘉湃富」，申请日 2025.08.14，发明申请。

**② 文本**：数出来了这些

| 数什么 | 值 | 说明 |
|---|---|---|
| 权 1 的附图标记 | 0 个 | 没有任何结构描述 |
| 权 1 由"获取/判断/输出"起头的分句 | 100% | 全是通用动作 |
| "单元/模块，用于" | 4 处 | 功能性模块 |
| 编号实施例 | 0 个 | 没给可实现的方案 |
| 性能测试表 / 测试数值 | 0 / 0 | 没给验证数据 |
| 背景技术引用在先文献 | 0 处 | 没做检索比对 |

对照条款：第十条（功能性模块 ≥3 处且无模型、无实施例）**成立**；第十六条（无引用、无表、无数）**成立**。

**③ 结论**：第十条是硬证据，单独成立就定案 → **非正常**，不必再查主体。

**对照案例**：`CN118852128A 含2-吲哚酮的喹唑啉衍生物`，有 9 个实施例、2 张性能测试表、66 处带单位参数 → 第十六条豁免，文本判正常。查到社保 0 人（该公司 2020 年成立）→ 只有 1 项主体事实、文本又没命中 → 记**存疑**，人工看一眼社保是不是年报没报。

## 三、判决表

| 情形 | 结论 | 下一步 |
|---|---|---|
| 第十二条或第十条单独成立 | 非正常 | 结束 |
| 其他手段条款 + 第十六条同时成立 | 非正常 | 结束 |
| 只有一个手段条款，或只有第十六条 | 存疑 | 查主体 |
| 主体 ≥2 项成立，或 1 项成立且文本有命中 | 非正常 | 结束 |
| 主体 1 项成立、文本无命中 | 存疑 | 人工复核 |
| 全部不命中 | 正常 | 要跑完 T23/T25/T26 才算 |
| 拆分型成立 | 不改档 | 只作支撑，写进报告说明段落 |
| 数据拿不到 | 待核 | 不猜 |

硬证据只有两条：**第十二条**（结构堆砌：部件 ≥12、装配 ≥5、无参数、无实施例）、**第十条**（功能性模块 ≥3 处）。其余手段条款都要配上第十六条才算数——它们单独命中时，十个里有一两个是正常案件。

第十六条是三样同时缺才算成立：**背景没引用在先文献、没有性能测试表、没有测试结果数值**。有任一样就放行；只有引用、没有表没有数的，记存疑。

## 四、数据从哪来、花多少

| 查什么 | 平台 | 成本 |
|---|---|---|
| 授权发明专利件数 | incoPat | 每申请人 1 次，约 75 秒 |
| 社保、经营范围、行业 | 企查查 `qcc company get_company_registration_info` | 每申请人 1 次，约 1 秒 |
| 代理师 12 个月代理量 | 香橼树代理师月度统计 | 每人 1 次 |
| 发明人名下件数 | incoPat | 每人 1 次，约 75 秒 |

去重很关键：446 件案子只对应 203 个申请人、295 个发明人。按件查会白花 4–15 倍时间。

## 五、怎么跑

```bash
# 文本步：一条命令出三档，逐案一行 JSON
python3 scripts/text_screen.py <某批 PDF 目录> --json 结果.json

# 出报告
python3 scripts/build_report.py 结果.json -o 报告.md --title 批次名

# 复核阈值是否还站得住（会重算全部数字）
python3 scripts/experiment_order.py --pos <非正常样本目录> --neg <正常样本目录>
```

主体要调平台，命令见 `references/data-sources.md`；缓存 90 天，查过的别重查。

## 六、什么时候不适用

- **创造性不足**：技术简单不算非正常，按审查意见处理。
- **权利要求写窄了**、**同一主题拆成多件**、**违法公德**：不在本流程范围。
- **院校、医院、研究所**：不因身份命中，技术方向超出经营范围是常态。
- **实用新型**：不适用第十六条，只看手段；没有手段命中的列存疑，不放正常。

## 八、边界

- 只判上面列出的判据，不自创指纹、模板套话、相似度打分。
- 数据拿不到记待核，不默认通过，也不凭空判不过。
- 结构案（第十二条、第十一条第一项）出结论时附"核对附图"，图文排版会让附图标记数差 2–26 个。
