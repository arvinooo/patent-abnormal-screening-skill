# 维度总表（同一层，23 项）

> 所有判据平铺在这里，不分阶段。检测顺序不写在本文件——顺序由 `references/ordering.md` 的实验结论决定，改顺序不改判据。
> 阈值与 `thresholds.md` 一一对应；本表只增加"成本"与"实测"两列。

## 列的含义

| 列 | 含义 |
|---|---|
| 方向 | **判硬**：单独命中即定非正常。**判软**：须与 T11 同时成立才定案。**筛**：命中只排待查。**救**：命中即排除非正常。 |
| 成本 | 一次判决要付的取数代价；按去重键计，不按件计 |
| 键数 | 446 件实测语料里的去重键个数，由 `scripts/experiment_order.py` 输出（`references/ordering.md`） |
| 实测 | 在 446 件语料上的命中分布：正例命中 / 反例命中，精确率 |

## 四、成本合计（446 件）

| 跑法 | 查询次数 | 每次查询管多少件 |
|---|---|---|
| 逐案全查 | 446 × 7 ≈ 3 122 | 0.14 |
| 按去重键全查 | 11 + 203×2 + 295 + 44 = 756 | 0.59 |
| 批次 → 文本 → 尾部主体 | 11 + 176 = 187 | 2.4 |

去重键是本表的核心信息：同一批里 446 件只对应 203 个申请人、295 个发明人、44 个代理师、11 家机构。任何"按件取数"的设计都会白付 4–15 倍成本。
