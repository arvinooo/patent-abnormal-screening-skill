# 第一层跨案：拆分型与复制型

> 只在一次送审 ≥2 件时判；单件送审记"未核（单件）"。判据在 `非正常判定标准.md` 第二十七条，本文只写怎么成组、怎么数。
> 两项都是**一票否决**：成立即判非正常，不与第十六条搭配，也不看手段判据是否命中。

## 一、成组

```text
同一申请人 ≥2 件
且 组内各件申请日跨度 ≤12 个月
且 组内每件都有文本
```

- 申请人取自首页著录项，名称相同的视为同一主体；字号、简称不同的不自动并组。
- 关联主体（母子公司、同一实际控制人）的并组要工商数据，属主体步，第一层不并组。
- 只有 1 件的主体不构成组，不得为凑组并入邻组。
- 一案双申（同一申请号既有发明又有实用新型）只算 1 件。

## 二、拆分型（T13）

判据只有一条：**组内各件的发明名称全部围绕同一产品/设备**（产品级尺度读标题，不读正文）。

- 同一产品的结构件、控制方法、装配工艺、配套方法 → 算同主题
- 跨多类设备（硫化机、输送线、模具、管道检测）→ 不构成
- 同一产线上的两台不同设备 → 边界情形，默认不构成

判例：

| 组 | 标题概况 | 判定 |
|---|---|---|
| 某打印机企业 9 件（69 天） | 结构、控制方法、切刀、散热、装配工艺、蓝牙打印、图片裁剪 | 拆分型 |
| 某轮胎企业 9 件（12 个月） | 硫化机、输送线、组合模具、管道检测 | 不构成 |
| 某微流控企业 4 件（6 个月） | 清洗、喷墨补偿、打印数据生成、移液控制 | 拆分型 |

成立时组内各件均判非正常，报告写组内件数、产品线与申请日跨度。

## 三、复制型（T14）

正文二十字片段重合率 ≥50%，且技术问题、原理一致，差异仅参数。

```python
def shingles(text, k=20):
    t = "".join(text.split())
    return {t[i:i+k] for i in range(len(t) - k + 1)}

def overlap(a, b, k=20):
    A, B = shingles(a, k), shingles(b, k)
    return len(A & B) / max(1, len(A))
```

实测提醒：真实非正常案不靠文本雷同——同一批 103 对同主体配对中，重合率 ≥50% 的为 0 对，最高 28.1%。计算前按申请号去重（两件是同一件时重合率必为 100%）。

成立时两件均判非正常。

## 四、报告写法

```text
- 原因：本批 13 件全围绕「阀门」同一产品线，是同一产品的不同结构件分别申请
```

只写组内件数、产品线、申请日跨度，不写条款号。

## 五、边界

- 同主体跨产品线的多件（一家公司同时报设备和材料）不构成组。
- 送审文件不覆盖同一申请人的全部在申案件时，组可能不完整，报告写"组可能不完整"。
- 拆分型按标题成组判，产品线边界靠人读标题；判错会把整组判成非正常，拿不准的记"未核"并写清卡在哪。
