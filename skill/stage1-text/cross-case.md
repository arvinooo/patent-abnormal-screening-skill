# 跨案维度：拆分型与复制型

> 只在一次送审有 ≥2 件文本时判。单件送审不判，记"未核（单件）"。
> 本维度**不单独定案**，只作支撑说明；判据在根目录 `非正常判定标准.md` 第二十七条，本文只写怎么成组、怎么数。

## 一、成组

```text
同一申请人 ≥2 件
且 组内各件申请日跨度 ≤12 个月
且 组内每件都有文本
```

- 申请人取自首页著录项，同名的视为同一主体；字号、简称不同的不自动并组。
- 关联主体（母子公司、同一实控人）的并组要工商数据，属主体步，文本步不并组。
- 只有 1 件的主体不构成组，不得为凑组并入邻组。

## 二、拆分型

判据只有一条：**组内各件的发明名称全部围绕同一产品/设备**（产品级尺度读标题，不读正文）。

- 同一产品的结构件、控制方法、装配工艺、配套方法 → 算同主题
- 跨多类设备（硫化机、输送线、模具、管道检测）→ 不构成
- 同一产线上的两台不同设备 → 边界情形，默认不构成

判例：

| 组 | 标题概况 | 判定 |
|---|---|---|
| 某打印机企业 9 件（69 天） | 结构、控制方法、切刀、散热、装配工艺、蓝牙打印、图片裁剪 | 拆分型 |
| 某轮胎企业 9 件（12 个月） | 硫化机、输送线、组合模具、管道检测 | 不构成 |
| 某微流控企业 4 件（6 个月） | 清洗、喷墨补偿、打印数据生成、移液控制 | 拆分型 |

成组后逐件核对是否真拆：判**支撑**的，须在报告里写明组内件数、产品线与申请日跨度，不能只写"拆分型"。

## 三、复制型

正文 20 字片段重合率 ≥50%，且技术问题、原理一致，差异仅参数。

```python
def shingles(text, k=20):
    t = "".join(text.split())
    return {t[i:i+k] for i in range(len(t) - k + 1)}

def overlap(a, b, k=20):
    A, B = shingles(a, k), shingles(b, k)
    return len(A & B) / max(1, len(A))
```

实测提醒：真实非正常案不靠文本雷同——同一批 103 对同主体配对中，重合率 ≥50% 的为 0 对，最高 28.1%。**低重合率不等于不成组**，拆分型靠标题与主题判。计算重合率前按申请号去重（A/B 文本为同一件时重合率必为 100%）。

## 四、与三项判据的关系

拆分型与复制型都不构成独立判据，用途只有两个：

- 支撑手段判据：同一产品的第 N 件，从权只改一个零件，说明是拆量而非研发；
- 报告中作独立说明段落，写明组内件数与产品线。

不得据此单独判非正常，也不得据此把已判正常的案件改判。

## 五、边界

- 一案双申（同一申请号既有发明又有实用新型）只算 1 件。
- 同主体跨产品线的多件（一家公司同时报设备和材料）不构成组。
- 送审文件不覆盖同一申请人的全部在申案件时，组可能不完整，报告写"组可能不完整"。
