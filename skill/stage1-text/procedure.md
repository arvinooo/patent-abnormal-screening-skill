# 文本步作业规程：PDF 主体审核

> 判据在根目录 `非正常判定标准.md`，本文只写**怎么读、怎么算、怎么记**。冲突以标准为准。

## 一、抽取

1. 公开文本 PDF 取 `权利要求书`、`说明书`、`附图` 三段；正文起点找"权 利 要 求 书"与"说 明 书"，找不到时退回"权利要求""说明书"。
2. **公式、表格、部分附图是位图**，文字层为空。判定"有无公式/有无表"按标准第十三条第二款的引导语口径：引导语后紧跟无文字区域即视为已记载，不得因抽不到字符判"无"。
3. 首页著录项取：申请号、申请日、申请人、发明人、代理机构、代理师、专利类型、发明名称。
4. 抽完先核对完整性：权利要求书、说明书、背景技术、具体实施方式四段是否都在；单一文本少于 2 000 字或说明书少于 1 500 字的，标"抽取不完整"，不得据此判正常。

## 二、计数口径

| 计数 | 口径 |
|---|---|
| 部件数 | 图上/权项里的附图标记数近似；与手数部件不等同，结论附"核对附图"提示 |
| 装配关系数 | 固定连接、套设、铰接、滑动连接、螺纹连接等出现的处数 |
| 说明书带单位参数 | 数字 + 单位（mm、℃、MPa、%、min、重量份等）的出现次数 |
| 编号实施例 | "实施例 N""实施方式 N"列明的方案个数；"实施例用于解释本发明"不计 |
| 八字片段重合率 | **只保留汉字**后取连续 8 字片段比对；剔除数字、标点、附图标记 |
| 段落平均字数 | 按 `[00xx]` 段计；无编号段落的，按空行分段 |
| 有益效果段范围 | 从"有益效果/技术效果/优点"标题到"附图说明/具体实施方式/实施例"之间 |

## 三、判定顺序

1. 读权 1：能否说出"以何种手段解决何种技术问题"。说不出 → 记手段判据，继续走条款。
2. 按标准第三章逐条核：第九、十、十一、十二、十三、十四、十五。命中任一即停，记条款号与原文。
3. 分档：命中第十二条或第十条的记为**硬证据**，直接出非正常；其余手段条款记为**软证据**，继续第 4 步。
4. 核第十六条：有无在先文献引用、性能测试表、测试结果数值。三者皆无才成立。
5. 软证据与第十六条同时成立 → 非正常；只有一个 → 存疑；都没有 → 正常。

## 四、判定单（每件一张）

| 字段 | 要求 |
|---|---|
| 公开号、申请号、申请日 | 取自首页著录项 |
| 专利类型 | 发明申请、发明授权、实用新型 |
| 申请人、发明人、代理机构与代理师 | 首页照录；发明人栏为"请求不公布姓名"的照录 |
| 结论 | 非正常、存疑、正常 |
| 触发条款 | 例：第十一条第一项、第十二条、第十六条 |
| 原文证据 | 每条判据配一句原文与段号，不得转述 |
| 计数 | 部件数、装配关系数、编号实施例数、带单位参数处数、有益效果段重合率、有无性能测试表 |
| 撰写痕迹 | 零展开、解释式复述、权利要求内嵌效果结论，有则记 |
| 未核项 | 抽取不完整、条款无法判断的，写"未核"并注明原因 |

存疑案随单移交主体步，附上以上字段。

## 五、常见坑

- 把说明书里的"检测结果""测试结果"当成验证数据：软件类常是中间输出物名（"输出 J 个检测结果"），不算。
- 把配方表、组分表当成性能测试表：不算。
- 把"实施例用于解释本发明"当成实施例：不算。
- 用说明书篇幅、附图张数当判据：标准明确不以篇幅、附图数量为准。
- 高校院所案按企业阈值套：先按标准第五条分层，再核实现方式。
- 实用新型套用第十二条或效果判据：不适用。
